## 專案分工

| 路徑                                  | 用途                                     |
| ----------------------------------- | -------------------------------------- |
| `WcgWeb/Models`、`WcgWeb/Services`   | 共用卡牌資料模型、遊戲規則、AI、牌組驗證與天梯結算             |
| `WcgWeb/Components`、`WcgWeb/Client` | 共用畫面與 Phaser 戰場；名稱為魂誓，圖標為 🔮           |
| `WcgWeb/Services/Hosting`           | 原伺服器專用的檔案讀寫及建構方式                       |
| `SoulOath.Static`                   | 新的 Blazor WebAssembly 入口，遊戲與 AI 在瀏覽器執行 |
| `SoulOath.Static/Services`          | 瀏覽器儲存介面、備份驗證                           |
| `SoulOath.Static/tools`             | 準備公開資源、壓縮卡圖、測試、輸出與本機靜態預覽               |
| `SoulOath.Site/dist`                | Sites 專用、可獨立上傳的完整靜態檔案                  |
| `玩家存檔備份` | 本機玩家備份，不納入 Git 或部署 |
| `deployment`、`docs` | 部署設定範本與整理後的說明文件 |

原 `WcgWeb` 伺服器版本保留，可繼續執行；靜態版與伺服器版共用規則原始碼。靜態版不包含內部動畫實驗頁。

## 玩家資料

網站只提供卡牌、預組、對手牌組、圖片和程式檔案。遊戲沒有帳號、雲端資料庫、跨裝置同步、多人對戰或全服排行榜。Sites 的私人網站存取驗證與遊戲存檔分開；目前僅擁有者可存取網站。

自訂牌組與天梯進度存放在該網站來源的 `localStorage`，根鍵為 `soul-oath.player.v1`。能量操作設定與側邊欄寬度也存在本機。天梯對局會記錄種子與操作，刷新後可還原；一般人機測試局刷新後重新準備。

同一瀏覽器的多個分頁只能有一個分頁寫入存檔，以 Web Locks 避免互相覆蓋；其他分頁可閱讀，儲存時會提示關閉另一個分頁後刷新。儲存失敗或資料不正確時保留原資料。使用新版瀏覽器並以 HTTPS 開啟正式站；localhost 可用於本機測試。

設定頁提供匯出 JSON 備份及匯入。匯入先檢查格式、卡牌 ID、50 張限制、混色限制、天梯資料與對局還原，通過後顯示確認取代按鈕。清除網站資料或換裝置前先匯出。

本機網址與正式網址各有自己的存檔，部署不會自動搬移。原伺服器存檔另備份於 `玩家存檔備份/2026-10-04-靜態化前.json`，可於正式站設定頁匯入，未包含於網站輸出。若之後原伺服器繼續產生進度，部署前需要再備份最新資料。

## 重建與本機試玩

需要 .NET 10 SDK、Node.js、Python 3 與 Pillow；原戰場前端使用原有 npm 鎖檔。此工作已使用本機現有工具完成建置。

在專案根目錄執行：

```bash
node SoulOath.Static/tools/build-site.mjs
node SoulOath.Static/tools/serve-static.mjs SoulOath.Site/dist 5180
```

本機網址：<http://127.0.0.1:5180/>。這個預覽只供應靜態檔案，不執行遊戲後端。

建置會先準備共用資源，再以 Release 輸出 WebAssembly，重建 `SoulOath.Site/dist`，移除 source maps、除錯檔和伺服器設定。公開路由各有 `index.html`，能在一般靜態主機直接開啟或刷新。

卡圖保留原尺寸，123 張 PNG 轉成 WebP，約 346 MB 降至約 45 MB。原始卡圖保留。另提供 123 張列印專用 JPG，約 11 MiB（卡面使用約 300 dpi）。完整部署目錄約 106 MiB，包含 WebAssembly 執行環境及預壓縮檔；卡圖依畫面載入，並非首次開頁一次載入全部圖片。
