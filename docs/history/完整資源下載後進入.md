# 完整資源下載後進入

2026-10-08。原啟動讀條只計算 Blazor 啟動檔案，199 張卡圖會在遊戲內陸續下載，導致圖鑑出現空白圖片。

靜態版現在先下載完整公開資源清單：199 張卡圖、199 張列印圖、音效、字型、介面、卡片資料和遊戲程式。此次輸出共 673 項，約 127.6 MB。全部取得並通過 SHA-256 與大小檢查後才啟動遊戲；未完成或失敗不能進入。

- 讀條顯示實際準備的資源大小、百分比與完成項數，串流下載時也會更新。
- 最多同時下載六項，暫時連線失敗重試；仍失敗時提供重新整理入口。
- 已驗證的完整檔案以內容雜湊保存在專用瀏覽器快取。重新整理接續缺少檔案，更新只下載改變的內容。
- Service Worker 從該快取提供圖片、音效與程式，遊戲內不用重新從伺服器下載卡圖。靜態版卡圖改用 eager 載入。
- 每個開啟分頁綁定自己的完整版本；工作程序重新啟動後仍可恢復。首頁與資源清單繼續取得更新。
- 不攔截頁面導覽、跨站請求、寫入或預下載請求。不碰玩家存檔、牌組、訓練場保存資料。
- 瀏覽器不支援快取或空間不足時顯示原因；不會以不完整資源開放遊戲，也不會刪除玩家資料。

## 驗證

39 項靜態版檢查通過，涵蓋完整下載門檻、並行限制、中斷接續、快取重用、只補更新內容、串流進度、404／毀損檔案、儲存額度不足、清單範圍以及跨分頁版本恢復。

本地 Chrome 模擬 128 KB/s 與 120 ms 延遲，3% 時仍停在下載畫面。故意阻擋第 199 張卡圖後，82% 顯示下載未完成且未開放遊戲；390×844 手機寬度無水平溢出。解除阻擋後重新整理從既有 83% 資源接續。

184 項 .NET 檢查亦通過。完整下載後正常進入訓練場，既有自訂牌組仍在。斷線後從選單開啟圖鑑，199/199 張圖片 complete 且 naturalWidth > 0，199 筆圖片回應均由 Service Worker 提供，沒有下載失敗。再次以慢速網路刷新圖鑑，沒有任何卡圖預下載請求，199 張圖片再次從已保存資源顯示。所有網路／尺寸模擬已解除。

截圖保存於被忽略的 `output/full-preload-slow.jpg` 與 `output/full-preload-failure-mobile.jpg`。

## Azure 發布與限制

27 個變更檔案、約 0.65 MB 的增量包部署成功；首頁、資源清單、預下載模組、工作程序、啟動程式及新應用程式 wasm 的線上 SHA-256 與本地輸出相同，MIME 正確。本地 5180 已更新，服務保持 active；Sites checkout 未改動。

線上 Chrome 顯示 40% 的完整資源下載，途中於 49% 遇到 HTTP 403 `Site Disabled`。管理 API 確認 `state=QuotaExceeded`、`usageState=Exceeded`；方案配額 API 的 `BytesSent` 為 219,627,513 bytes，上限 173,015,040 bytes（165 MiB）。CPU 只使用約 14.5 秒，未達日上限，阻塞原因是每日輸出流量。下一次流量重置為 2026-10-09 00:00 UTC，即台灣時間 2026-10-09 08:00。

因此 Azure 完整進入遊戲的最終驗證尚未完成，需等額度重置後重新整理接續下載。沒有反覆重新下載全部資源或更換付費方案。已保存的約 64 MB 資源仍在瀏覽器。F1 不適合多人各自首次下載約 128 MB 的完整遊戲，後續應另行選擇適合的 Azure 靜態檔案服務或主機方案。
