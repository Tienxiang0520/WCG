# 啟動下載進度條

2026-10-08，首頁原本只顯示「正在準備卡牌與對戰…」，慢速網路無法判斷下載是否仍在進行。

改為原生進度條與百分比，使用 Blazor 提供的實際啟動檔案載入比例。此比例依已載入檔案數量計算，包含快取，不是下載位元組比例，因此大型檔案下載時可能暫留同一百分比。

- 載入階段顯示「正在下載遊戲資料…」。
- 檔案達到 100% 後顯示「下載完成，正在準備卡牌與對戰…」。
- 遊戲畫面出現後，進度條移除且觀察器停止。
- 載入失敗時顯示錯誤與重新整理入口。
- 快取已完成的檔案直接反映進度，未設定最低等待時間。
- 讀條支援螢幕閱讀器；390 px 手機寬度無水平溢出。

只修改靜態版首頁與啟動顯示，未改動規則引擎或玩家存檔。

## 驗證與更新

33 項靜態版檢查通過，包含 4 項新增檢查：實際進度與啟動階段、快取直接完成、失敗停止更新、錯誤百分比保護。

Chrome 測試分頁模擬 64 KB/s 與 120 ms 延遲，本地讀條從 14% 推進至 41%，恢復正常網路後進入訓練場。390×844 測試時頁面寬度為 390 px，讀條可見且無水平溢出。

Azure 線上分頁也顯示 93% 的讀條，下載後正常進入訓練場，成功載入流程的警告／錯誤紀錄為空。另在測試分頁暫時阻擋啟動程式，確認顯示「下載或啟動失敗，請重新整理再試」，解除阻擋後可重新整理恢復。所有網路與尺寸模擬均已解除，測試分頁關閉。

本地 5180 已更新，服務未重啟。Azure 以 20 個變更檔案、約 0.61 MB 的增量包更新，保留原檔案與既有快取相容性。線上首頁與 `startup.js` 的 SHA-256 與本地新輸出一致，新應用程式檔案可正常取得。Sites 未發布。
