# v0.6 訓練場

2026-10-08，將人機對戰入口改為訓練場，使用獨立規則引擎、操作橋接與電腦協調器。測試指令須由訓練引擎啟用；一般與天梯引擎拒絕訓練操作。原有扇形手牌、箭頭、拖曳與戰場卡圖沿用共用戰場元件。

第一版包含：搜尋199張卡並加入任一方手牌；指定格位直接擺放、觸發進場或背面蓋牌；調整生命／能量；卡片直立／橫置／移至墓地；電腦預設暫停、自動行動與單步；保存、還原及重新整理後載入同一場面。工具面板開啟時暫停電腦並阻止戰場拖曳，收起後恢復操作。

保存為獨立瀏覽器資料，只接受卡庫中存在的卡、合法陣營及不重複格位。保存時不能有待結算效果；還原清除原待結算流程，建立新對局識別碼，重新計算持續效果，避免舊命令或快取污染。跨分頁過期寫入及儲存失敗保留上一份場面，不修改牌組／天梯資料。

驗證涵蓋一般引擎拒絕測試修改、直接擺放與進場觸發差異、非法格位／能量／資料不修改對局、附著法術與基礎PP的多次還原、重新建立引擎後載入、待結算效果的限制，以及電腦暫停／單步與動畫確認。靜態資料檢查涵蓋獨立存檔鍵、過期寫入與儲存失敗保留舊資料。

操作方式見 [訓練場操作指南](../訓練場操作指南.md)。更新5180本地靜態版，保留玩家存檔，不發布Sites。

184項.NET檢查與29項靜態檢查通過。5180瀏覽器實測搜尋125、加入手牌及布置主動結界、調整雙方生命與可用／橫置能量、比較焦土縱火犯的直接擺放與進場傷害、電腦暫停與單步填能量、指定格位橫置／直立／移至墓地、保存後還原，以及重新整理後載入，瀏覽器無警告或錯誤。驗證畫面保存在忽略的 `output/v06-training-tools.jpg`。
