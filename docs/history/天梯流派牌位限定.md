## 牌位限定方式

`tools/RankedDecks/build_ranked_decks.py` 的每個流派改用 `tiers=(…)` 明列可出現的牌位（`TIER_GATES`），不再自動繼承低牌位的所有流派。同一流派在不同牌位依該牌位的降級組數產生不同版本。

### 解讀與建議（尚未實作）

1. 曲線整體平順，沒有斷崖；公平對局維持五成，難度主要來自電腦分級。
2. **（已採用，見下節）暗影刺殺**從黃金起就是各牌位最強（同牌位 73～79%），黃金、白金對大師級玩家也近五成，比同池其他流派高約 20 個百分點。建議改為只在鑽石與大師出現，或至少移出黃金。
3. **大師**的誓約審判、白銀長城對強玩家約八成。若希望大師「難但可打」，可：
   - 保留它們作為大師魔王，但降低抽中機率；或
   - 移出 1～2 個，換回戰鼓狂潮、灰燼殉爆等較平衡的流派，讓大師對角線接近 55%。
4. 白金→鑽石是最大一階。可把巨獸奔襲或聖盾防線的鑽石版本換成較弱流派，或讓冰封堡壘只在大師，以縮小落差。
5. 奧術控制、占卜連鎖、噬魂獻祭即使對同牌位玩家也只有 25～30%，在青銅～白金當「好打」的對手合理，不必調整。

### 決定性修正

建立矩陣時發現：黃金以上電腦在多選一抉擇分數相同時，以選項 Id 排序作為最後依據。卡牌選項的 Id 是每場隨機產生的 GUID，所以同一種子可能做出不同選擇；天梯回放（新的 GUID）也可能與原對局分歧。

已改為：GUID 選項同分時依選項順序決定，具名選項（KEEP、HEAL 等）維持原本的字母排序，因此不影響電腦強度。此修正屬於同一個未合併 PR 內的 `RankedAiVersion` 4，不需再升版。

新增測試 `TieredAiReplaysWholeGamesIdenticallyDespiteFreshInstanceIds`：各級電腦以相同種子完整打兩次，逐步比對。修正前失敗，修正後通過。
