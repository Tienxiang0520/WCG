# 教學卡片資料同步

2026-10-13

「結界與手牌反擊」課程仍把熔火鍛爐寫成 3 費，但現行卡片是 2 費；出牌後的提示也把剩餘能量寫成 3 點，實際應有 4 點。其他課程還留著鐵木樹人、白銀持戟禁衛和鐵壁騎士的舊 PP。

教學的卡片說明與操作提示改為以卡片 ID 綁定資料。卡名、費用、DP 與效果文字讀取對局使用的卡片資料庫；交戰 PP 讀取場上怪物的目前戰力，包含附著與光環加成；剩餘能量讀取當下可用能量。沒有對應場上怪物時，PP 使用卡面數值。中英文提示先翻譯說明格式，再填入相同卡片 ID 的名稱、卡文與數值，錯誤操作提示也會填入卡名，不會留下格式代號。

共 82 段說明與提示改為資料綁定。具體卡牌效果改為引用現行卡文，仍保留召喚到哪一格、攻擊哪個目標等操作指引。一般法術教學同步修正：不指定目標的法術拉出手牌後，在戰場空白處放開，不用指向玩家頭像；卡面費用位置也修正為右上角。

沒有更動卡片數值、效果、玩家存檔或課程完成進度；14 課與原本的固定教學場面保留。未來如果平衡調整會改變場面的勝負關係或是否有足夠能量，仍須執行教學完成測試核對場面設計。
