# 反擊費用不足說明

翻開蓋牌不代表反擊成功。原本費用不足時，卡片送入墓地且攻擊繼續，但對戰紀錄僅顯示「翻開蓋牌」，容易誤認為反擊免費發動。

現在反擊費用不足的翻牌紀錄顯示「費用不足，反擊未發動（需要 2，可用 0）；蓋牌已送墓地。」數字依當下實際費用與直立能量顯示；卡名仍可點開查看。英文介面也提供對應翻譯。

這次只補說明，保留反擊、扣費、AI 選擇與舊天梯對局的結算行為，不更改卡牌強度或存檔格式。

驗證：342 項 .NET 測試通過。新增 0、1、2 點可用能量的情境，確認不足時不扣能量、攻擊繼續、卡片送墓地，費用足夠時仍正常扣費並消滅攻擊者；同時核對公開事件的卡名與中英文訊息。

前端驗證：70 項測試通過，Azure 靜態包檢查通過。在獨立訓練場布置敵方 3 點總能量、0 點可用能量與亡魂索命陷阱，實際拖曳攻擊並單步讓 AI 翻牌；確認對戰紀錄顯示新增說明、敵方生命由 7 降至 6、攻擊者留場。
