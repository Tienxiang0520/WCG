# 🔮《魂誓》WCG 啟動與操作指南

本專案為原創 2 人對戰卡牌遊戲《魂誓》，採 WCG（Web-to-Card Game）形式，提供網頁遊玩、學習、50 張牌組構築、卡牌圖鑑及實體牌組列印。專案資料夾為 `/home/pudding/project/WCG`；最新靜態版與列印操作見《靜態部署說明.md》及《列印說明.md》。

> 卡牌資料已改為 v0.4 試玩版，能量規則為任意手牌背面填能量、每回合一張、不抽牌、橫置支付通用費用；已取消專用能量卡；組牌須選定主色，其他四種意志合計最多 12 張，主色及中立沒有額外張數限制。前後端已同步能量、額外代價、逐卡效果、指定攻擊、四種狀態及 AI 生命週期，修復與驗證範圍詳見《前後端修復紀錄.md》。

## 對戰操作

卡面或「查看卡片」只查看詳情；召喚／施放與背面填能量使用獨立按鈕。點己方可攻擊怪物，再點亮框的敵方怪物或「攻擊電腦玩家」；有有效嘲諷時須先攻擊嘲諷。每次攻擊結算後可繼續出牌或攻擊，不再安排阻擋或進入戰術窗口。聖盾保留的能量不能付款；狀態與附著法術顯示在場上怪物。

電腦逐步行動，可勾選加快速度。離開對戰頁會停止節奏工作，同一瀏覽器連線返回可繼續；重新整理或服務重啟不保存對局。重開新局會替換對局版本，舊畫面操作被拒絕。

舊自訂牌組仍保留，含舊能量 ID 或不足／超過 50 張時不能開局，須自行載入編輯。存檔失敗顯示錯誤；其他分頁改過同牌組時須重新載入，避免覆寫。未儲存的牌組編輯尚未提供草稿恢復。

組牌室提供主色選單及「主色／混色 0～12／中立」張數統計。更換主色會重新計算混色額度；超額時不可儲存或開局，原編輯內容保留。舊存檔未指定主色時須載入後選擇主色再儲存。

## 瀏覽器測試工具

已安裝 `agent-browser 0.38.1`，使用者設定已指定電腦既有 Chrome，可直接執行 CLI；額外 Chrome 下載逾時，不影響以下已驗證方式。此工具不屬於遊戲相依套件。

```bash
agent-browser --session wcg-check --executable-path /usr/bin/google-chrome open http://localhost:5169
agent-browser --session wcg-check snapshot -i
agent-browser --session wcg-check close
```

啟動開發服務請使用上述 `dotnet run`（套用 Development launch profile），不要以未發佈的 Production 執行檔測試，否則靜態 CSS／Blazor 腳本可能無法載入。

## 最新對戰介面

手牌固定底部：滑過放大，點選後出現召喚／施放與填能量。填能量預設先確認，可關閉。點己方怪物再滑過敵方看交戰預覽；桌面點擊目標直接攻擊，觸控先預覽再確認。紀錄可以收合，狀態與能量保留直接顯示。詳見《操作手感改版紀錄.md》。最新自動測試為 82 項通過。

拖曳操作：手牌拖到己方戰場召喚、拖到能量區填能量；己方怪物拖到合法敵怪或敵方生命區放開攻擊。非法放置取消，Escape 可中止。手機短按攻擊仍先預覽再確認，拖曳攻擊則放開執行。法術施放目前仍點選。
