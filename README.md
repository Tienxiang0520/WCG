# WCG · 魂誓

**WCG（Web-to-Card Game）**

一種以網頁作為主要遊玩、學習與構築平台，但所有核心規則皆可由實體卡牌執行，並允許玩家將數位牌組輸出為可列印實體牌組的構築式卡牌遊戲。

WCG 是本專案採用的遊戲形式與資料夾名稱；本作遊戲名稱為「魂誓」。

## 專案位置

`/home/pudding/project/WCG`

實際資料全部位於 WCG。原 `/home/pudding/project/Lcg` 相容連結已於 2026-10-05 移除，請使用上述專案路徑。

## 主要內容

| 資料夾 | 用途 |
| --- | --- |
| `LcgWeb` | 共用遊戲規則、AI、卡牌、畫面及原伺服器版 |
| `LcgTests` | 規則與遊戲驗證 |
| `SoulOath.Static` | 在玩家瀏覽器執行並儲存資料的靜態版 |
| `SoulOath.Site` | 準備給 Sites 的靜態部署輸出 |
| `output/pdf` | 已輸出的實體牌組列印檔 |

內部程式專案名稱和卡牌編號保留，以維持現有牌組、玩家資料和建置相容。
