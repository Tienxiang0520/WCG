# PR #3 同步本地與 Azure

2026-10-09，將主線 `abb2769`（已合併 PR #3）重新建置並更新本地 5180 與既有 Azure Blob 靜態網站。

## 更新內容

- 深色金色介面、SVG 導覽圖示與嘲諷盾形卡框。
- 墓地及事件卡片預覽、共用音效管理與三組音量設定；保留既有 A 木質結束回合音效。
- 最近 30 場天梯紀錄、逐步回顧及自動播放、賽後查看對手牌組。
- 組牌的單色／雙色卡池篩選。

沿用天梯存檔版本 2、天梯行動版本 4。本次沒有修改卡片規則、天梯牌組或重置玩家進度。

## 驗證時修正

回顧畫面底部控制列在桌面與手機尺寸會蓋住手牌，造成滑鼠點擊無法開啟預覽。調整 `RankedReplayViewer.razor.css`：頂部及控制列保留高度，中央內容獨立捲動。修正後以滑鼠及 390×664 手機模擬尺寸確認卡片預覽可開啟，且控制列不再重疊手牌。
