# 天梯多樣性與數值平衡

日期：2026-10-10。基準版本：`50a37d0`（PR #10 之後）。

本輪保留現有 199 張卡，僅調整 32 張的費用、PP 或 DP；效果、關鍵字、箭頭與開局規則均沿用原版。新增的是牌組組合，不是新卡。

## 牌組範圍

- 流派：20 → 30；分段牌表：75 → 136。
- 青銅／白銀／黃金／白金／鑽石／大師的流派數：11／20／24／24／27／30。每段都有五種意志。
- 每副 50 張、同名最多 4 張、最多兩種意志、副色最多 12 張；每副都有至少三種合法微調。保留強勢流派的段位門檻。
- 玩家可直接選擇 5 副試玩預組與 30 副完整參考牌組；參考牌組可複製另存、修改及列印。

新增：復燃連擊、熔爐戰線、回音法陣、時空突擊、根鬚覺醒、森靈回流、聖光遠征、淨化壁壘、瘟疫復甦、殘血魔潮。

既有秘法、觀星、吞魂與森林鋪場重新搭配怪物、抽牌、犧牲與收尾卡，減少只抽牌、無傷害怪物占場及缺少召喚目標的問題。

## 配對模擬

使用 `BalanceLeague`，雙方都由相同等級 AI 操作；30 副牌組兩兩交手，435 組對戰，每組 32 個種子且交換先後手，調整前與後各 27,840 場。兩次使用相同最終牌表，僅卡片數值不同。每副各 1,856 場。種子基數 900000，配對種子由牌組 ID 的 SHA-256 決定。

| 指標 | 調整前 | 調整後 |
|---|---:|---:|
| 最低牌組勝率 | 28.23% | 35.83% |
| 最高牌組勝率 | 79.36% | 69.56% |
| 牌組勝率標準差 | 13.30 個百分點 | 9.74 個百分點 |
| 先手勝率 | 64.04% | 66.36% |

另外用白金策略（AI 3）測試 13,920 場，範圍 31.03%～74.46%，先手勝率 60.31%。森林鋪場仍只有 31.03%，巨獸壓境達 74.46%；這是策略敏感度的實際限制，不能宣稱所有玩家或 AI 下都已平衡。先手優勢也仍需後續處理；本輪依要求先維持數值與牌組範圍。

這些都是模擬 AI 勝率，不是人類勝率。卡片與勝率關聯也不等於單卡造成的因果效果。固定對手與配對種子非獨立人類樣本；工具附的 Wilson 區間僅作描述。對称循環賽平均必為 50%，不以此宣稱平衡。

## 存檔與驗證

- 新增 `balance-before-diversity.json` 保存 32 張舊數值；新版續玩舊局時使用原卡池，下一局才用新數值。PR #10 後的舊局不開啟更早年代的 LegacyCardRules。更早年代的指紋與回放也保留。
- 不重置段位、戰績或玩家頭像，不覆蓋自訂牌組；內建參考牌組複製才會成為玩家自己的牌組。
- .NET：310 項通過；前端：70 項通過；Blob 部署工具：9 項通過。靜態輸出檢查 199 張圖、1294 檔案、150.1 MB。
- generator 的 `--check`、卡片文件一致性檢查、分段微調合法性與卡片總量檢查皆為獨立驗證；136 副及 570 個微調皆通過，六段各抽選 200 次且沒有連續重複流派。
- agent-browser 使用獨立測試 session 與 5186 測試站；透過真實滑鼠拖曳、點擊與公開 DOM 觀察。已續玩 PR #10 舊局完成勝利並加星，再打開回顧跳到結局；新版回音法陣完成另一場勝利，確認新的費用與 DP。參考牌組從 UI 複製、儲存後，唯讀工具確認新 GUID 與完整 50 張。大量循環賽由規則引擎執行，不宣稱那些場次都是瀏覽器逐場操作。

重現方法與試玩入口見 [天梯牌組與平衡測試](../天梯牌組與平衡測試.md)。配對摘要與版本雜湊見 [平衡數據](天梯多樣性平衡數據.json)。完整逐對輸出保留於本地忽略目錄 `output/balance/`。
