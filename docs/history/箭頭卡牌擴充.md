# 箭頭卡牌擴充（站位效果）

分支：`arrow-cards`（自 `card-face-redesign` 分出；依賴 PR #5 i18n、#6 效果動畫、#7 卡面重新設計——卡面與戰場的金色三角箭頭來自 #7）

## 目標

原本只有秩序的 3 張卡（WCG-061 / 073 / 147）有箭頭，而且箭頭只代表「給聖盾」。這次逐張檢視全部 199 張卡，挑出「白板身材」或「效果單純」的怪物加上站位箭頭，讓五大意志都有符合個性的站位玩法：

| 意志 | 箭頭玩法 | 卡牌 |
| --- | --- | --- |
| 狂怒 | ↑ 劈砍正對面；← → 衝鋒帶隊 | 156、005 |
| 理智 | 依站位抽牌；↑ 橫置正對面 | 021、033 |
| 生機 | ← → / → 光環培育隊友 | 055、157 |
| 秩序 | （維持）箭頭分配聖盾 | 061、073、147（未改） |
| 深淵 | ↑ 離場同歸；↑ 壓低正對面 PP | 159、085 |
| 中立 | ↑ 壓低正對面 PP | 114 |

挑選原則：不動法術／結界／蓋牌；不動已有複雜觸發的卡；不動稀有度主軸卡；身材效果合計後費用曲線不變（費用全部不變，強化的卡以 PP 下修換取效果）。

## 箭頭規則

- ← →：連到己方左右相鄰格；↑：連到正對面同列格（己方第 n 格對敵方第 6−n 格）。
- 光環（005/055/157 加友軍、085/114 減敵軍）是持續效果：來源被沉默、離場或格位不再相鄰，加減值立即消失；不會作用在來源自己身上。
- 只有 061/073/147 的箭頭給聖盾（`GameEngine.ShieldArrows`），其他箭頭卡只用箭頭決定自己的效果範圍。
- 進場／離場效果以「效果結算當下」的格位判斷。159 離場時已不在場上，以它原本所在的列判斷。

## 程式

- `GameEngine.V06.cs`：力量公式加入 `ArrowPower`（`ArrowAura` 表列 5 張光環卡）；聖盾資格限定 `ShieldArrows`；`ArrowTargets` 回傳箭頭連到的怪物。
- `GameEngine.Effects.cs`：021 / 033 / 156 進場、159 離場。新分支都以「該卡有箭頭」為條件，舊版卡牌資料（無箭頭）走原本的程式路徑。033 橫置時送出「橫置」展示事件（效果動畫 PR 的徽章）。
- `GameEngine.V06Ai.cs`：電腦選格時，↑ 箭頭對著敵怪改為加分（147 的 ↑ 會給敵方聖盾，仍扣分）；左右箭頭原本就會找有隊友的格位。
- 卡面／戰場：沿用 #7 的金色三角（`face-arrow`、`.arrowmark`）；效果文字中的「【箭頭：…】」不重複印出（005「衝鋒；」後面的箭頭標記也會移除）。

## 天梯與回顧版本

天梯存檔記錄的是卡牌資料的 SHA-256 指紋（`ranked-v06:`）。這次改了卡牌資料，所以指紋會變：

- 新增 `Data/balance-before-arrow-cards.json`（9 張卡的舊定義，嵌入資源 `WcgWeb.Balance.BeforeArrowCards`，WcgWeb 與 SoulOath.Static 都有嵌入）。
- `CardBalanceHistory.BeforeArrowCards` 還原箭頭擴充前的卡表；更早一版的 `BeforeUnlimitedFactionTriggers` 改為疊在它上面，指紋仍與當時發佈的一致。
- 測試鎖定兩個歷史指紋：箭頭前 `3664E962…A2CE`、陣營觸發無上限前 `4ED3BFBD…A194`。
- 進行中的舊對局：照舊卡續玩，顯示「本局沿用原卡牌效果與費用，下一局套用新版。」；下一局使用新版。
- 已結束的舊對局：回顧以舊卡表重新模擬，可正常播放；更早、無法辨識的版本仍顯示「這場對局使用的卡牌版本已更新，無法重新模擬回顧。」。
- `RankedAiVersion` 不需要調整：AI 與引擎的新分支只在卡牌有新箭頭時生效，舊卡表重播結果完全一致（測試以狀態快照比對）。
- **天梯星數不重置**，季別與歷季成績不受影響。

## 已知限制

- 箭頭光環在戰場上直接反映在 PP 數字（例如 900），沒有額外的「光環來源」連線動畫。
- 033 的橫置不會檢查「冰凍／已橫置」的特殊互動，已橫置的敵怪仍算被選中（不抽牌）。
- 平衡數據是 AI 對 AI 的模擬，不代表真人勝率。
