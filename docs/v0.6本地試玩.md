## 開始與操作

1. 進入首頁，選擇名稱以「v0.6」開頭的預組，按「開始對戰」。建議先用秩序牌組，熟悉061、073、147箭頭與聖盾。
2. 每回合選一張手牌按「填能量」。原有「填能量前再次確認」設定仍有效；開啟時先確認，取消不移動卡片。
3. 按怪物「召喚」或結界「放置結界」，先選空格，才付款進場。進場後不能換位置；敵方格位從對手視角編號，正對面的實體欄位保持對齊。
4. 怪物直立時可按「選擇攻擊者」，再按敵怪「攻擊此怪物」或「攻擊電腦玩家」。合法嘲諷仍須優先。攻擊完成橫置；轉直立效果可以恢復攻擊能力。
5. 任意手牌按「0費蓋牌」並選空格。玩家被攻擊時可翻一張，真正反擊仍須保留足量直立能量。
6. 有聖盾資格的怪物將被交戰消滅時，會詢問是否橫置1能量保命。不支付就正常消滅。資格不因使用消失，但能量已用掉。
7. 附著效果顯示在目標下方；主動結界按「發動結界」。完成必要選擇才可繼續行動；尚未付款的指定及格位可以取消。
8. 按「結束回合」，電腦會逐步出牌、選格、使用結界、蓋牌與攻擊。有防守選擇時會停下等待你，不是卡住。

目前使用文字卡面，箭頭印在卡片邊緣，直立／橫置同時以文字與顏色區分。未製作正式卡圖，也未搬回舊動畫戰場。對戰紀錄與墓地可展開閱讀。

```bash

```
