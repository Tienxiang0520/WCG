# 前端視覺重新設計（2026-10）

## 目標

保留 PR #2 已經調好的所有互動細節（戰鬥特效、手機直式半露手牌、英雄頭像與點臉攻擊、頭像選擇與上傳、toast 修正、`--wcg-vh`／`dvh`／safe-area 處理），只重做「看起來的樣子」，讓整個前端像同一位 UI 設計師做出來的作品。

不改遊戲規則、AI、存檔格式、天梯資料或重播決定性。所有圖形都是自製的 SVG／CSS，沒有外部 CDN、字型或有版權的素材。

## 設計方向：「暗金典藏」

- **底色**：黑曜石色的深色表面（`--wcg-bg`、`--wcg-surface-*`），背景加上很淡的金色與青色光暈。
- **主色**：古金 `--wcg-gold #d6b46c` 與漸層 `--wcg-gold-grad`，用在主要按鈕、選中狀態、標題裝飾與卡框。
- **語意色**：
  - 秘術青 `--wcg-teal #5fd3bd`：可行動、可放置、合法目標。
  - 餘燼紅：危險、敵方、PP。
  - 藍寶石色：能量、費用、DP。
- **意志色**：狂怒、理智、生機、秩序、深淵、中立各有一個 token，篩選晶片和卡框都用同一組顏色。
- **字體**：標題用系統襯線字（Noto Serif TC／Songti／PMingLiU 等字型堆疊），內文用 CJK 無襯線；數字用 tabular-nums。
- **圖示**：新增 `Components/Common/Icon.razor`，內含一組 24×24 線條 SVG 圖示，取代導覽列和按鈕上的 emoji。
- **Token**：`app.css` 改寫成設計系統，`:root` 裡定義顏色、字級、間距、圓角、陰影、focus 環與動畫曲線，並把 Bootstrap 變數接上這些 token。按鈕、表單、卡片、badge、alert、modal 都已重新上色。

## 共用元件（`wcg.css`）

- `page-hero`：每頁一致的頁首，包含小標（eyebrow）、襯線大標題、導言和金色分隔線。
- `wcg-panel` 與 `panel-title`：玻璃感深色面板，標題前有金色菱形。
- 其他控制項：
  - `segmented`：分段切換。
  - `filter-chip`、`will-chip`、`cost-chip`：篩選晶片，意志晶片帶色點。
  - `search-field`：搜尋框。
  - `wcg-field`：表單欄位。
- `.wcg-card`：卡片重做，包含燙金內框、意志色外框、費用寶石、類型條、PP／DP 標籤。
- 卡片詳情 modal、toast 的成功與錯誤圖示，以及規則頁排版。
- 頁面 `h1` 被 Blazor 程式化聚焦時不再顯示 focus 框。

## 補充：天梯對戰紀錄與對局回顧（新功能）

### 之前已有 vs 這次新增

- **之前已有**：天梯只保存「最後一場」對局（`Match`：種子、牌位、先後手、規則指紋、雙方牌組、行動序列）與其結算（`Result`），以及每季摘要（`History`，大廳的「歷季成績」）。沒有逐場對戰清單，也沒有回顧畫面。對戰中的「紀錄／墓地」卡名預覽（上一節）天梯也共用。
- **這次新增**：
  1. **對戰紀錄**：天梯大廳新增「對戰紀錄」面板。每場顯示勝敗、星數變化、日期時間（台灣時間）、對手流派與主意志、我方使用牌組、牌位變化（前 → 後）、回合數、對局時長。可切換「本季／全部」。對戰結算畫面也多了「對局回顧」按鈕。
  2. **對局回顧**：全螢幕回顧檢視器。它用當局的隨機種子與已記錄的行動，在一個獨立的引擎上重新模擬，逐步顯示雙方生命、能量、手牌數、牌庫數、雙方場上五格（敵方格位反向，與對戰畫面一致）、我方手牌、雙方墓地、本步事件與累積紀錄。
     - 控制鈕：回到開局、上一步、播放／暫停、下一步、跳到結局，加上可拖曳的進度條，以及 0.5×／1×／2×／4× 速度。
     - 所有卡名（場上、手牌、墓地、事件、紀錄）都能點擊，打開卡片預覽；關閉後回到原本的步驟。

### 資料格式與相容性

- 存檔新增兩個**選填欄位**：`RankedProfile.Records`（最多保留最近 30 場，超過就從最舊的開始丟棄）和 `RankedMatch.StartedAt`。**沒有**提高 `ProfileVersion` 或任何行動、規則版本，既有存檔不會被重置。
- 舊版程式讀到新存檔時會略過不認得的欄位。新版讀到舊存檔時 `Records` 為空；若最後一場已結算的 `Match` 還在，會自動補進紀錄（沒有開始時間，時長顯示「—」）。
- 每場紀錄保存雙方牌組、種子、規則指紋，以及壓縮成一行字串的行動序列（`type,source,side,target,choice,rulesVersion;…`）。單場約數 KB，30 場的整份存檔測試確認小於 400 KB。
- 讀檔時會逐筆檢查紀錄，損壞的紀錄（牌位越界、行動無法解析、規則版本不明等）直接略過，不會擋住天梯。
- 紀錄跟天梯存檔放在一起，所以伺服器版（伺服器端 JSON）和靜態版（瀏覽器儲存）都適用，備份與還原時也會一起帶走。

### 不洩漏非公開資訊

回顧畫面使用與對戰畫面相同的玩家視角快照和事件。電腦的手牌只顯示張數，電腦抽到的牌不顯示名稱，雙方的蓋牌都顯示為牌背「魂誓」，不能點開。回顧在獨立引擎上執行，不會動到進行中的天梯對局、行動紀錄或存檔。

### 音效

- 打開或關閉回顧和卡片預覽時，沿用全站的 modalOpen／modalClose 音效。點卡名播放翻牌（flip）。
- 上一步、下一步播放 select；播放、暫停播放 toggleOn／toggleOff；回到開局播放 back。
- 自動播放時，每一步依事件挑一個代表音效（擊殺、攻擊、受傷、召喚、出牌、蓋牌、回血、能量、換回合、抽牌）。
- 為此，`data-sfx-show` 新增選用的 `data-sfx-delay` 屬性，可以立即播放。

### 限制

- 只會列出這個功能上線後完成的對局，加上上線時存檔裡的最後一場。更早的對局沒有保存行動，無法補回。
- 如果卡牌平衡版本之後又更新，而舊紀錄的規則指紋已不在支援清單內，該場會顯示「卡牌版本已更新，無法重新模擬回顧」，但紀錄本身仍會保留。
- 回顧以「行動」為單位逐步顯示，不逐格重播攻擊動畫。
- 驗證：dotnet test 新增 4 項天梯測試（逐場紀錄與回顧終局一致、30 場上限與存檔大小、舊存檔補登、損壞紀錄略過）；Playwright 在桌面與手機直向實際打天梯、投降、開啟紀錄與回顧、逐步／自動播放／拖曳進度、點卡名預覽並關閉，主控台無錯誤。截圖：`ranked-history-*.png`、`ranked-replay-*.png`、`ranked-replay-preview-*.png`、`ranked-history-preview-*.png`。

## 補充：對戰紀錄的對手牌組

- 每一列對戰紀錄多了「對手牌組」按鈕。展開後列出電腦當場實際使用的 50 張牌組（包括當局隨機微調的 0～2 組卡牌），依費用排序，顯示張數並以意志色標示。點任一卡名都能開啟卡片預覽，關閉後回到展開的清單。
- 儲存方式：對戰紀錄原本就保存了電腦當場的完整牌組（回顧重新模擬時也需要），所以這次**不必新增任何欄位**，也不必另外存牌組 id 或變體編號。這樣也避免日後牌組池調整時，用 id 反查到不同的牌表。若某張卡已不在目前的卡表中，清單會略過它並提示。
- 對局結束後才看得到，屬於賽後公開資訊；對局進行中的畫面不受影響。

## 補充：牌組構築室依組色篩選

- **之前**：玩家牌組只有「主色」欄位，規則是最多兩個派系（中立不計）、每張卡最多 4 張。卡牌庫永遠顯示全部 199 張，要到加入時才被「最多兩個派系」擋下。
- **現在**：主色下方新增「單色／雙色」切換，選雙色時可指定副色（也可以先不定，加入第一張副色卡時自動決定）。卡牌庫只顯示這副牌組能放的卡：
  - 單色：主色＋中立。
  - 雙色：主色＋副色＋中立。
  - 雙色但副色未定：全部意志都顯示，因為任一副色都合法。
- 意志篩選列會同步顯示組色：主色標「主」、副色標「副」，不能用的意志變成虛線並鎖住（顯示鎖頭）。篩選列下方有一行「依組色顯示：狂怒＋理智＋中立」。不在組色內的卡，「＋ 加入」按鈕會停用並說明原因。
- 如果把雙色改回單色，或換了副色，而牌組裡還有不符合的卡，會顯示提醒和張數。這些卡仍可在「目前牌組」與右側清單中看到並移除。
- 單色／雙色只是構築時的選擇，**不寫進牌組存檔**：每次開啟牌組時，會依照裡面實際使用的派系自動判斷，所以牌組檔案格式與合法性規則都沒有改變。尚未選主色的新牌組會顯示全部卡片，並提示先選主色。
