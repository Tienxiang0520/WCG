# WCG 命名整理

完成日期：2026-10-05。

## 統一的名稱

- 主程式與測試專案改為 `WcgWeb/`、`WcgTests/`，更新專案檔、命名空間、共用程式引用、測試與工具的路徑。
- 前端套件名稱使用 `wcg-battle-client`，樣式檔使用 `wcg.css`，卡面類別與能量設定鍵使用 `wcg` 前綴。
- 123 張卡牌的現行編號使用 `WCG-001` 至 `WCG-123`，同步預組、天梯對手、程式效果、卡表、試算表、美術資料與卡圖檔名。
- 現行文件與工作目錄內的歷史改版說明統一使用 WCG 名稱。Git 封存版本仍保存當時原始內容，不改寫既有提交。
- 遊戲名稱仍為「魂誓」；本次只整理命名，卡牌能力、數值與對戰規則沒有調整。

## 舊資料相容

- 舊牌組編號在讀取時對應到現行編號；舊存檔原始檔案不會因改名而被重寫，後續儲存與匯出使用現行編號。
- 同一張卡的新舊編號合併計算，不能用混合編號繞過每張最多 4 張的限制。
- 以原版程式產生含兩次真實操作的天梯對局測試資料，確認改名後還原的牌序、能量與對局狀態完全一致；真正改動卡牌數值仍會被規則版本檢查攔下。
- 舊能量確認設定與舊匯出備份可沿用；匯入失敗會回復原存檔與設定，遇到新舊設定衝突時拒絕匯入。
- 相容讀取程式與 `WcgTests/Fixtures/` 的原版測試資料刻意保留舊識別前綴。玩家備份與 Git 歷史也保留原貌；這些不是現行顯示名稱。
