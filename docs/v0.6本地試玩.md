## 開始與操作

1. 進入首頁，選擇名稱以「v0.6」開頭的預組，按「開始對戰」。建議先用秩序牌組，熟悉061、073、147箭頭與聖盾。
2. 手牌固定在下方，重疊成扇形；滑鼠移上卡片會浮起放大。左鍵開啟詳情彈窗，不直接出牌。
3. 拖一張手牌到左下能量區填能量。原有確認設定仍有效；取消確認不移動卡片。
4. 正面怪物或結界拖到己方空格，付款後固定在該格；法術拖到亮起的合法目標，無指定目標法術拖到戰場中央。
5. 右鍵手牌切換蓋牌模式，再右鍵翻回。此時仍留在手牌；將背面牌拖到己方空格才以0費蓋牌進場。
6. 直立怪物拖向合法敵怪或上方電腦生命區即可攻擊；嘲諷仍須優先。攻擊後橫置，轉直立效果能恢復攻擊能力。
7. 主動結界左鍵開詳情，再按「發動結界」。效果抉擇、聖盾與反擊使用彈窗；需要指定場上卡片時點選亮框。
8. 按住拖曳時只顯示指向箭頭，原卡留在原位；合法落點呈綠色，非法落點呈紅色。放開在合法落點後才播放卡片移動，再結算：召喚／蓋牌飛入指定格，法術飛向目標後消失，填能量縮入能量區；攻擊前衝後返回原格。開啟填能量確認時，確認後才移動，取消不移動。動畫期間暫停其他操作。非法拖放或Escape取消不播放移牌動畫、不支付費用。完成回合按右側「結束回合」，「紀錄／墓地」可查看資訊。

目前使用文字卡面，箭頭印在卡片邊緣，直立／橫置同時以文字與顏色區分。戰場、指向箭頭、扇形手牌、放開後的移牌動畫及彈窗分層顯示，尚未製作正式卡圖。桌面滑鼠為主要操作方式；鍵盤聚焦手牌後Enter開詳情，S切換蓋牌模式。

在專案根目錄執行：

```bash

```

