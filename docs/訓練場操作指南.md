# 訓練場操作指南

本地入口：<http://127.0.0.1:5180/>。左側「訓練場」。訓練對局不寫入天梯、玩家存檔或重播。

1. 選雙方牌組與先攻，按「開始訓練」；或在「快速情境」直接一鍵載入預設場面（見下表）。電腦預設暫停。
2. 按右上「測試工具」。工具開啟時暫停電腦，收起後即可正常拖曳手牌或怪物。
3. 選己方或電腦，搜尋卡名／編號。「加入手牌」把指定卡片加入該方手牌；「放到牌庫頂」把該卡放到牌庫頂（牌庫裡有同名卡就移動那張，沒有就新增一張）；「抽 1 張」讓該方從牌庫頂抽 1 張。
4. 選空格，按「直接擺放」建立直立卡片，不觸發進場／召喚效果；「進場並觸發效果」使用原本進場結算，不扣費。
5. 修改生命、總能量與可用能量，按「套用生命與能量」。生命0–7，能量0–30；可用能量不可超過總量。「回合數」可改成 1–999。
6. 從「調整場上卡片」選格位（含結界），可轉直立、橫置或移至墓地（不觸發死亡效果）。
7. 指示物：選好場上卡片後，直接填倒數、DP、聖盾、腐蝕、血誓、聖泉指示物的數量（0–20），按「套用指示物」。這是直接設定，不觸發放置效果；倒數設成 0 也不會觸發歸零效果。要測歸零，設 1 後按「結束目前回合」兩次（或讓對手回合結束），在你的回合開始時移除。
8. 「結束目前回合」直接結束目前行動方的回合（不論是你或電腦），回合開始的轉直立、倒數移除等照正常規則結算。
9. 「互換雙方（操控對手）」：把兩邊整個交換，原本的對手卡片、手牌、生命、能量移到你這一側，用一般操作替對手出牌、攻擊、結束回合；再按一次換回。引擎只有一個人類座位，所以這是交換座位而不是同時顯示兩邊的手牌介面。互換時電腦暫停。
10. 「恢復電腦自動行動」讓電腦依規則持續操作；「電腦執行一步」只在電腦有行動或選擇且已暫停時有效。
11. 待選效果：有效果等你選擇時，工具會顯示提示。可以在戰場完成選擇，或按「取消待選效果（回到效果前）」回到最後一個沒有待選效果的場面。待選期間不能改場面（避免效果結算到一半被改壞）。
12. 保存場面：輸入「場面名稱」，按「另存新場面」或「覆蓋選取場面」。「已保存場面」可選擇後還原、改名為上方名稱、刪除。最多 30 個，存於此瀏覽器 `wcg.trainingScenes.v2`。舊版單一保存 `wcg.trainingScene.v1` 會自動出現為「舊保存場面」，原資料保留不刪。入口頁也可直接選擇已保存場面載入。

## 快速情境

| 情境 | 卡片 | 怎麼測 |
|---|---|---|
| 嘲諷阻擋 | 己方 沼澤巨鱷、淡水狂鱷；電腦 白銀巡邏衛（嘲諷）、巡邏輕步兵 | 攻擊頭像或巡邏輕步兵會被擋；擊破嘲諷怪後可打頭像 |
| 怪物對打 | 己方 沼澤巨鱷 1900、淡水狂鱷 1300；電腦 巡邏輕步兵 1000、淡水狂鱷 1300 | 1900→1000 防守方破；1300 對 1300 兩邊都破 |
| 倒數計數 | 己方 星沙學徒（1）、封時守衛（2）、倒懸時鐘（1）；電腦回合 | 按「結束目前回合」：星沙學徒歸零抽 2、封時守衛 2→1、倒懸時鐘歸零選擇消滅敵方怪物 |
| 翻開牌庫頂 | 手牌 擲骨巫童、黑籤召喚師；牌庫頂 雪人巨獸 | 召喚擲骨巫童看翻開 |
| 橫置與回合開始轉直立 | 己方兩隻怪物橫置；電腦回合 | 結束回合後轉直立；新召喚的怪物橫置進場 |
| 敗北 | 你 1 點生命、沒有怪物；電腦有直立怪物，電腦回合 | 電腦執行一步或恢復自動行動 |
| 勝利 | 電腦 1 點生命、沒有怪物 | 用沼澤巨鱷攻擊頭像 |

「牌位保護」只在天梯敗北時出現，訓練場依設計不碰天梯紀錄，所以沒有這個情境；要測請在天梯實際敗北。
