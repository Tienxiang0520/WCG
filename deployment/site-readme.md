# 魂誓 WCG · Sites 靜態網站

**WCG（Web-to-Card Game）**：一種以網頁作為主要遊玩、學習與構築平台，但所有核心規則皆可由實體卡牌執行，並允許玩家將數位牌組輸出為可列印實體牌組的構築式卡牌遊戲。

本作名稱為「魂誓」。`dist/` 包含網站所需的 HTML、CSS、JavaScript、WebAssembly、公開卡牌資料、WebP 圖片與列印用 JPG。

## 遊玩與資料

遊戲、AI、自訂牌組與個人天梯在玩家瀏覽器運作。自訂牌組、設定和天梯進度存放於該網站來源的本機瀏覽器儲存；沒有遊戲帳號或跨裝置互通。設定頁可匯出、匯入備份，切換正式網址時需自行匯入本機備份。

牌組構築室提供實體牌組列印：彩色或省墨、A4 直向、63 × 88 mm 卡牌，50 張共 6 頁，可加兩張生命計數卡及 1 頁規則清單。列印內容在玩家裝置產生。

## 部署

本目錄為獨立 Sites 原始碼來源，只同步本目錄；上層玩家存檔、備份、驗證資料和伺服器原始碼不包含在內。

`.openai/hosting.json` 保存 Sites 註冊後取得的 `project_id`，`static.directory` 設為 `dist`。不使用遊戲後端、資料庫或物件儲存。Sites 的分享與存取範圍由網站設定管理，與遊戲存檔分開。

上層原始碼位於 WCG 專案中的 `SoulOath.Static` 與 `LcgWeb`。在上層執行 `node SoulOath.Static/tools/build-site.mjs` 可重建本目錄的 `dist`。正式網址與部署狀態以 Sites 回傳結果為準。
