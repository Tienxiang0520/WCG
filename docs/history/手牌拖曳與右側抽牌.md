# 手牌拖曳與右側抽牌

依卡片當下的操作類型呈現拖曳，不再替所有卡片畫箭頭。

- 指定怪物或玩家的法術，以及怪物攻擊：保留瞄準箭頭、合法目標與吸附提示。
- 不指定目標的法術，包括抽牌與全場效果：卡片跟隨游標或手指。向上拉出手牌區一段距離後放開施放；短拖、拉回手牌、放到頭像或操作按鈕上，以及移到戰場外均取消。施放前仍由規則引擎驗證費用與合法性；需要後續抉擇或犧牲的卡片照常等待選擇。
- 怪物、結界、蓋牌：卡片跟隨拖曳，空格提供落點框，沒有瞄準箭頭。固定格位規則維持原樣。
- 填能量：明確拖到能量區時優先填能量，保留原本確認畫面，不會被誤判為施放法術。

抽牌動畫從右側牌庫方向飛向手牌，對手抽牌仍只顯示牌背。墓地回收與取得卡片不套用牌庫出發位置。

修改限介面與動畫，不更改卡牌文字、強度、規則版本或存檔格式。沒有新增外部素材，也沒有生成卡圖。

驗證：342 項 .NET 測試、75 項前端測試及 Azure 靜態包檢查通過。獨立瀏覽器在 1440×900 與 390×844 尺寸實際操作，確認抽牌卡短拖與拉回取消、頭像不作為抽牌目標、放開施放且正確扣費抽牌、右側抽牌出發點、回血箭頭與選定玩家、怪物與結界無箭頭放置、能量確認、攻擊箭頭與 Escape 取消；瀏覽器沒有 JavaScript 錯誤。手機尺寸使用模擬環境，未宣稱實機驗證。

拖曳預覽停用手牌原本的發牌入場動畫，避免複製卡片延遲出現；不指定目標時也不標紅游標下的怪物或格位。
