# 傷害後從手牌反擊

現行設計保留數字生命與原本 7 張起手牌，不增加生命牌、牌庫翻牌或受傷抽牌。蓋牌玩法取消；手上的反擊牌在受到生命傷害後取得發動機會。

## 判定與操作

傷害先扣血，再檢查受傷方手牌。只有傷害來源、合法目標與能量費用都符合卡文的反擊才列入選擇；沒有合法反擊就不彈窗。玩家可以略過，略過與不符合條件都保留手牌、能量。發動從手牌支付費用，通常送墓地；198 成功附著則留在怪物下方。

彈窗列出傷害來源、可用反擊的卡文與費用。新對局移除右鍵／詳情中的蓋牌按鈕與訓練場蓋牌操作；反擊手牌標示「等待反擊」。教學的「結界與手牌反擊」改成受到傷害後從手牌發動。

生命傷害包括怪物攻擊、法術、怪物進場／被動、結界被動、陣亡與反擊造成的傷害。付生命代價不是傷害，不開啟反擊機會。減傷後為 0 也不開啟反擊。

## 結算順序

扣血 → 合法手牌反擊 → 反擊效果與新傷害的反擊 → 判定生命是否仍為 0 → 對局未結束時繼續來源的後續效果。

抵銷只補回該次實際失去的生命，最多一次，沒有額外抽牌、也不取消原卡全部效果。例如先造成傷害、後抽牌的法術，反擊結束且對局未結束後仍執行抽牌。致命傷害也保留反擊救援機會；沒有合法反擊或略過，不能等待原卡後面的回血。需要抽牌時牌庫空仍立即敗北。

若反擊未抵銷傷害且尚有其他合法手牌，可繼續選擇；抵銷後關閉這筆傷害的機會。另一張反擊造成新的傷害，另開受傷方的反擊機會。攻擊不改指其他目標；存活的攻擊者在原攻擊結束後橫置。
