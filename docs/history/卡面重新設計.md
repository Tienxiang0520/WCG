# 卡面重新設計（對齊實體卡）

分支：`card-face-redesign`（自 `effect-animations` 分出，因為法術展示也改用新卡面；依賴 PR #5 與效果動畫 PR）

## 目標

讓遊戲內卡面與實體卡（參考圖：秩序「銀色誓言衛」WCG-061）一致，同時保留對戰中精簡卡的尺寸、點擊範圍、嘲諷盾框裁切與手機半隱藏手牌。

## 完整版卡面 `CardFace`

`WcgWeb/Components/Common/CardFace.razor` + `wwwroot/card-face.css`（全域樣式，靜態網站也一併輸出）。全部為自製 CSS／SVG，未使用外部圖檔。

| 元素 | 作法 |
| --- | --- |
| 象牙羊皮紙底 | 多層漸層＋細斜紋 |
| 華麗金框＋星形飾 | 漸層金邊（mask 鏤空）＋內細線 SVG；四角、上下中央、標題下方 7 顆四芒星 SVG |
| 卡名（左上） | 金色漸層襯線字＋閃光星；長名（多為英文）自動縮字 |
| 費用圓章（右上） | 象牙圓底、金色多重圈，「2費」／「2 Cost」 |
| 意志・類型帶 | 「秩序・怪物」，左側細色條為意志色（輕微點綴） |
| 卡圖窗 | 金邊框；方向箭頭改為金色三角，畫在圖窗左／右／上緣並突出卡框 |
| 效果框 | 淡羅盤浮水印 SVG；卡牌文字開頭的「【箭頭：…】」改由金三角表達，不重複印出；長文字分級縮字 |
| 頁尾 | 「力量 1000 PP ✦ 傷害 1 DP」（法術／結界不顯示） |
| 底線 | 「魂誓」＋卡號「WCG-061」 |

尺寸全部以容器單位（cqw）計算，同一份標記可用於圖鑑小卡與大預覽。

使用位置：卡牌圖鑑（格狀＋詳情）、牌組構築（格狀＋詳情）、對戰中點卡放大、對戰紀錄／墓地與天梯對局回顧的卡片預覽（`CardPreviewDialog`）、效果動畫的法術展示（JS 版 `faceCard()`，結構與 CSS 相同）。

## 精簡版（戰場、手牌）

`BattleBoard.razor.css` 末段覆寫，未改任何尺寸或點擊區：

- 戰場：滿版卡圖外加象牙內緣＋金色雙線（敵方為紅金），卡名放在羊皮紙名牌，PP／DP 改為象牙金圈圓章（PP 紅字、DP 藍字）。嘲諷卡維持原本盾框裁切（規則特異度較高，不受影響）。
- 手牌：象牙底、金框、金邊卡圖，費用圓章維持在左上（扇形手牌右側會被下一張蓋住），手機半隱藏手牌不變。
- 方向箭頭：原本的青色箭頭改為金色三角，位置相同，敵方卡仍鏡像。

## 多語言

所有字串沿用既有英文對照（費→Cost、力量→Power、傷害→Damage、魂誓→Soul Oath、意志與類型名稱）；JS 法術展示的對照加入 `battle-feedback.js` 的 EN 表。英文卡名、效果文字以長度分級縮字。

- `battle-feedback.test.mjs`：法術展示為完整卡面（費用、意志類型帶、金三角、卡號）。
- Playwright：圖鑑、詳情、牌組構築、對戰（桌機／手機、中／英），主控台錯誤 0；截圖 `/workspace/wcg-shots/cardface/`，含與參考圖並排 `side-by-side-WCG-061.png`。

## 限制

- 實體列印版（`DeckPrintPreview`）維持原設計，未改。
- 圖鑑小卡（188px 寬）上的效果文字較小，完整閱讀需點開詳情。
- 參考圖的卡框雕花以星形與雙線近似，未逐筆描繪。

實作：

- `card-face.css` 改為主題變數（底紋、框體四階金屬色、卡名漸層、圓章、類型帶、效果框底與字色、浮水印、箭頭漸層、光暈）。秩序沿用原本的值（預設值），其他意志以 `article.wcg-face[data-will=…]` 覆寫；非秩序的角飾會鏡像到四角。
- `Services/CardFaceThemes.cs`（命名空間 Components.Common，放在 Services 讓靜態網站也會編譯）：每個意志的角飾、卡名飾、寶石與浮水印 SVG；`CardFace.razor` 依意志輸出。法術展示（`battle-feedback.js` 的 `faceCard()`）使用同一份形狀（`FACE_THEMES`），測試確認兩邊一致。
- 精簡版（戰場、手牌）：`.field-card`、`.v06-hand-card` 加上 `data-will`，邊框、名牌、PP／DP 圓章、手牌底紋、費用圓章與箭頭三角都改用同一套意志配色；蓋牌與秩序維持原樣（秩序的敵方卡仍是紅銅內框）。嘲諷盾框裁切不變。
- 測試：`CardFaceTests` 新增「每個意志輸出自己的角飾與浮水印、只有秩序有四芒星」與「C# 與 JS 主題形狀一致、CSS 有每個意志的主題」。
- 截圖：`/workspace/wcg-shots/cardface2/`（`lineup-zh.png`／`lineup-en.png` 六種卡框並排、`zoom1-zh.png`／`zoom2-zh.png` 放大、`zh-desktop-board-triggers.png` 混合意志戰場、`zh-desktop-board-taunt.png` 嘲諷裁切、`zh-mobile-board-triggers.png` 手機）。

## 實體列印也改用新版卡面（`print-card-faces`）

玩家回報：牌組編輯器的「列印實體牌組」仍印舊版卡面。彩色列印現在直接使用遊戲內的 `CardFace`（各意志卡框、角飾、浮水印、箭頭三角），中英文皆同。

尺寸與版面（沿用原本的列印規格，未更動）：

- 卡牌 **63 × 88 mm**（標準撲克／TCG 尺寸），A4 直向每頁 **3 × 3 = 9 張**，卡與卡之間 2 mm 溝槽；50 張卡共 6 頁，生命計數卡放在最後一頁空位，規則速查表另 1 頁。
- `@page` 邊界由 8.5 mm 改為 6 mm，頁面內左右各留 2.5 mm，讓溝槽外側的裁切線也落在可列印範圍內（卡片位置與尺寸不變）。
- 每張卡（含省墨版與生命計數卡）四角都有裁切線：0.1 mm 黑色細線畫在 2 mm 溝槽內，延伸卡片邊緣；相鄰四張卡的裁切線在溝槽中形成小方框。彩色版不再畫虛線外框，省墨版保留淡灰虛線。
- 每頁 `break-after: page`、每張卡 `break-inside: avoid`，卡片不會跨頁。

彩色列印的處理：

- `DeckPrintPlan` 的 `PrintedCard` 多存一份箭頭（快照，之後改卡資料不影響這次列印）；`PrintedCard.Face` 轉成 `BattleCard` 交給 `CardFace`。
- `CardFace` 新增 `ArtSrc` 參數：列印時用約 300 dpi 的 `print-art/{id}.jpg`，`loading="eager"`；遊戲內不變（`card-art/{id}.webp`）。
- `@media print` 對 `.print-sheet` 與所有子元素（含 `::before`／`::after`）設定 `print-color-adjust: exact` 與 `-webkit-print-color-adjust: exact`，背景與漸層會印出；頁邊空白改為白色（網站是 `color-scheme: dark`，Chrome 會把 PDF 頁邊塗成深色；列印時改為 `light`）。
- 卡面在列印格內固定為 63 × 88 mm（`1cqw = 0.63 mm`）：外陰影拿掉、外框黑邊改為內描，箭頭與上下寶石往內收，所有元素都在裁切範圍內（Playwright 檢查每張卡的子元素皆未超出格子）。
- Chrome 的列印／PDF 會丟掉 `mask-composite` 與 `background-clip: text`：卡框圓環會變成蓋住整張卡的漸層、卡名變淡。列印版改成「卡底畫框體漸層＋內縮一層畫各意志底紋」，卡名改為取自該意志卡名漸層的實色。
- 字級：效果文字 5.2cqw ≈ 9.3 pt；長英文最小一級由 3.5cqw 提高到 3.7cqw（≈ 6.6 pt），頁尾 ≈ 6 pt。
- 列印前（`deck-print.js` `printDeck`）：等字型、逐張 `image.decode()`，任何卡圖失敗就不開列印視窗；卡面效果框以文字段落的位置判斷是否溢出（效果框內有絕對定位的浮水印，不能用 `scrollHeight`）。
- 省墨文字版、生命計數卡、規則速查表與牌組清單選項都保留；省墨版仍是舊的純文字排版（不印圖片）。靜態網站與伺服器版共用同一份元件與 CSS。

測試與驗證：

- `DeckPrintFaceTests`：中英文渲染 `DeckPrintPreview`，每張卡都是 `wcg-face`、`data-will` 對應意志、輸出該意志的角飾與浮水印、箭頭數量與方向正確、卡圖為 `print-art`、不再出現舊的 `print-card-art`；六種意志都出現；英文版卡名與裁切說明為英文。另測 `DeckPrintPlan` 會帶入箭頭。
- `deck-print.test.mjs`：卡面效果文字超出框時阻止列印；只有浮水印超出時照常列印。
- Playwright：三副混色牌組（狂怒＋理智＋中立、秩序＋深淵＋中立、生機＋深淵＋中立，涵蓋六種卡框與所有箭頭卡）以 `page.pdf()` 匯出中英文，伺服器版與靜態版各一份；另以 5 副「全卡檢查」牌組涵蓋全部 199 張卡，中英文都沒有文字溢出、卡圖皆成功解碼。PDF 與 `pdftoppm` 轉出的 PNG 放在 `/workspace/wcg-shots/print/`。

限制：

- 沒有出血（bleed）：卡框直接畫到 63 × 88 mm 邊緣，裁切稍有偏差會露出白邊；卡面為圓角，裁切線標示的是直角外框。
- 瀏覽器列印對話框仍需使用者選「實際大小／100%」並開啟「背景圖形」（說明文字已提醒）；`print-color-adjust` 在多數瀏覽器會自動印背景，但 Firefox 的使用者設定可覆蓋。
- 光暈類 `drop-shadow` 濾鏡在 PDF 中會點陣化（角飾與箭頭本體仍是向量）；卡名改實色後少了金屬漸層。
- 印表機的實際色彩（尤其深色底的狂怒、理智、深淵）會比螢幕暗，大量深色底也較耗墨；需要省墨時請用省墨文字版。
