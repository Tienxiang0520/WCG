# WCG · 魂誓

**WCG（Web-to-Card Game）**

一種以網頁作為主要遊玩、學習與構築平台，但所有核心規則皆可由實體卡牌執行，並允許玩家將數位牌組輸出為可列印實體牌組的構築式卡牌遊戲。

WCG 是本專案採用的遊戲形式與資料夾名稱；本作遊戲名稱為「魂誓」。

## 專案位置

`/home/pudding/project/WCG`

專案資料位於上述 WCG 路徑。

## 主要內容

| 資料夾 | 用途 |
| --- | --- |
| `WcgWeb` | 共用遊戲規則、AI、卡牌、畫面及原伺服器版 |
| `WcgTests` | 規則與遊戲驗證 |
| `SoulOath.Static` | 在玩家瀏覽器執行並儲存資料的靜態版 |
| `SoulOath.Site` | 獨立 Sites Git 與靜態輸出，不納入主專案 Git |
| `deployment` | 可重建部署目錄的設定與說明範本 |
| `docs` | 操作指南、Git 使用說明與設計待討論內容 |
| `docs/history` | 歷次改版與平衡紀錄 |
| `output/pdf` | 已輸出的實體牌組列印檔 |

程式專案使用 WCG 名稱，卡牌編號統一為 `WCG-001` 至 `WCG-123`。相容讀取會辨識舊版存檔的編號；玩家資料不用手動重建。
