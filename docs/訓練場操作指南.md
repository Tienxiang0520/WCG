# 訓練場操作指南

本地入口：<http://127.0.0.1:5180/>。重新整理後，左側「人機對戰測試」改名為「訓練場」。不發布 Sites。

1. 選雙方牌組與先攻，按「開始訓練」。電腦預設暫停。
2. 按右上「測試工具」。工具開啟時暫停電腦，收起後即可正常拖曳手牌或怪物。
3. 選己方或電腦，搜尋卡名／編號。按「加入手牌」把指定卡片加入該方手牌。
4. 選空格，按「直接擺放」建立直立卡片，不觸發進場／召喚效果；「進場並觸發效果」使用原本進場結算，不扣費；法術可用「背面蓋牌」布置。
5. 修改生命、總能量與可用能量，按「套用生命與能量」。生命0–7，能量0–30；可用能量不可超過總量。生命設為0會正常判負，可還原保存場面重新測試。
6. 從「調整場上卡片」選格位，可轉直立、橫置或移至墓地。移至墓地不觸發死亡效果。
7. 「恢復電腦自動行動」讓電腦依規則持續操作；「電腦執行一步」只在電腦有行動或選擇且已暫停時有效。一步可能是填能量、選擇格位、效果選擇或攻擊，不一定完成整個回合。
8. 完成效果選擇後，按「保存目前場面」。之後可按「還原保存場面」，或重新整理後在入口按「載入保存場面」。每次保存取代上一份測試場面；還原時電腦保持暫停。

測試場面保留雙方手牌、牌庫順序、墓地、站位、生命、能量、卡片狀態、附著法術及回合。還原後重新建立卡片能力與箭頭判定，避免把附著加成重複加上去。尚有待結算效果時不能保存或修改場面；可還原已保存場面重新開始。

測試資料另存於此瀏覽器的 `wcg.trainingScene.v1`，不修改玩家牌組、天梯或既有玩家備份。第一版保留一份場面；沒有加入雙方手動控制、快速情境或多份場面管理。訓練場重新開局／重新整理會建立新對局；已保存場面仍可載入。
