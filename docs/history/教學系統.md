# 教學系統

日期：2026-10-09（台灣時間）

側邊選單新增「教學」。第一次進站會跳出「要不要開始新手教學」的視窗；共有 13 課：1 課新手教學、9 課對戰進階、3 課介面導覽，合起來涵蓋魂誓所有的機制與玩法。伺服器版（WcgWeb）與靜態版（SoulOath.Static）共用同一套元件與課程資料。

## 玩家看到的流程

1. **第一次進站**：彈出視窗，有三個選項。
   - 「開始新手教學」：記錄為已開始，並進入第 1 課。
   - 「稍後再說」：只在這次瀏覽中隱藏，重新整理後會再出現。
   - 「略過，不再提示」：記錄為略過，以後不再跳出。
   在教學頁與導覽頁不會跳出。
2. **側邊選單「教學」**：顯示完成數徽章（例如 `3/13`）。選單收合時會隱藏徽章。
3. **課程列表（`/tutorial`）**：
   - 頂部是進度環和「開始／繼續」按鈕。
   - 分成三組：新手教學、對戰進階、介面導覽。每課卡片列出主題標籤，完成的課會打勾。
   - 全部完成後顯示完成橫幅。
   - 可以重設教學進度（需要再確認一次）。
4. **互動對局課**（`/tutorial?lesson=<id>`）：
   - 在真正的對戰畫面上進行，場面固定。
   - 左側（窄螢幕在上方）是教練面板，顯示步驟、說明、進度與「重來」按鈕。
   - 畫面會調暗，並圈出要操作的卡片或格子。
   - 只接受這一步要求的動作；做錯會顯示提示，場面不會改變。
   - 可以隨時「重來」，還原同一個場面。投降或落敗後可以重新開始。
5. **介面導覽課**（`/deckbuilder?tour=deckbuilding`、`/ranked?tour=ranked`、`/settings?tour=settings`）：
   - 在真正的頁面上逐步說明，並聚光要講解的區域。
   - 「動手做」的步驟完成後會自動前往下一步。
   - 牌組導覽不會改動已儲存的牌組。天梯導覽中不會自動接續未完成的對局。

## 技術設計

- **課程資料**：
  - `WcgWeb/Services/Tutorial/TutorialModels.cs` 定義課程模型。
  - `WcgWeb/Services/Tutorial/TutorialLessons.cs` 定義 13 課。
  - 每課對局有固定場面 `TutorialScene`：雙方生命、手牌、牌庫、墓地、能量與場上卡，以及固定亂數種子。
  - 每個步驟定義：
    - 允許的動作 `TutorialAllow`
    - 完成條件 `Done`
    - 聚光目標 `Spot`
    - 做錯時的提示 `Hint`
- **場面載入**：
  - `GameEngine.Tutorial.cs` 的 `LoadTutorialScene` 只能在訓練模式使用。
  - 它透過既有的 `Change()` 清空並建立場面，不修改任何規則。
  - 正常對局、天梯與重播的流程完全沒有更動。
- **步驟驗證**：
  - `TutorialSession` 自己建立一個訓練用引擎、`BattleBridge` 與 `BattleCoordinator`。
  - 透過 bridge 既有的提交掛鉤檢查每個動作，不符合目前步驟就拒絕，場面不變。
  - 電腦回合依課程腳本行動，例如指定的攻擊；有選擇時交給既有的確定性 AI。
- **聚光**：
  - `wwwroot/battle/tutorial-spotlight.js` 用 SVG 遮罩把畫面調暗並圈出目標。
  - 這一層不攔截點擊與拖曳。
  - 出現對話框、拖曳中或卡片放大時，暫停調暗。
  - 導覽卡如果擋住目標，會移到另一側。
- **進度保存**：
  - 存在既有玩家檔的可選欄位 `tutorial`：`prompt` 記錄 `started` 或 `skipped`，`completed` 記錄已完成的課程 id。
  - 這個欄位為空時不會寫出，所以舊存檔不會因此改變內容。
  - 不新增儲存鍵、不變更天梯版本、不重設任何存檔；舊版程式會忽略這個欄位。
  - 讀到損壞的玩家檔時不會覆寫。
- **其他修正**：
  - 手機上拖曳時，被抬起的手牌可能蓋住能量區，導致放不進去。
  - 現在判斷放置位置時會略過被拖曳的那張卡（`fan-drag.js`），一般對局同樣受益。

## 已知限制

- 已經玩過的玩家，只要玩家檔裡沒有作答紀錄，也會看到一次首次進站視窗。選「略過」後就不會再出現。
- 「稍後再說」只對當次瀏覽有效。伺服器版是每次連線（circuit）各自計算。
- 冰凍與潛伏目前沒有任何卡使用，只以文字說明。隨機棄牌、回手等少數效果也只以文字說明，沒有獨立的實作步驟。
- 伺服器版沒有匯出／匯入存檔的介面，設定導覽的「存檔與備份」步驟在伺服器版只有文字說明，沒有聚光。
