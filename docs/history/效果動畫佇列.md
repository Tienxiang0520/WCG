# 效果動畫佇列（爐石式分步演出）

分支：`effect-animations`（自 `i18n-english` 分出，依賴 PR #5）

## 目標

把每一次伺服器回應中的事件，依序拆成「步驟」逐一播放，而不是一次全部閃過：

1. 法術：先在場中央展示卡牌（卡名＋效果文字），停留後縮到角落作為「來源」。
2. 依效果類型播放動畫：傷害飛彈／爆炸、治療光、抽牌飛卡、召喚、增益／減益數字、破壞、沉默、附著、能量、回手、棄牌。
3. 被動／觸發：來源卡先閃光並顯示效果名徽章（例如「進場能力」「發動結界」「聖盾」「嘲諷」「劇毒」「貫穿」「衝鋒」「反擊」），再以光束／光球連到受影響的卡，最後播放結果。
4. 光環（例如「相鄰友方獲得聖盾」）：從快照差異推得受影響卡片，由光環來源拉光束過去。
5. 每步之間有短暫停頓；電腦回合仍一步一步發布。

## 架構

| 檔案 | 內容 |
| --- | --- |
| `WcgWeb/wwwroot/battle/effect-plan.js` | 純函式規劃器：`planSteps(previous, next, events)` 把事件＋前後快照轉成步驟（event / showcase / source / badge / stat / tap），`batchSpeed` 依步數自動加速。沒有 DOM，可用 node 測試。 |
| `WcgWeb/wwwroot/battle/battle-feedback.js` | 播放器：依步驟呼叫 `showSpell`、`badge`、`beam`、`runEvent` 等；停頓本身也是 animation（方便測試與快轉）。 |
| `BattleBoard.razor.css` | `.event-showcase`、`.event-badge`、`.event-beam`、`.event-orb`、`.event-stat`、`.event-ff`、`.event-skip`、`.event-pause` 樣式。 |
| `GameEngine.Effects.cs`、`GameEngine.V06.cs` | 只新增三種「演出用」事件：進場能力（effect）、發動結界（effect）、附著（attach）。不改任何規則。 |

沒有事件的效果（PP 加成、橫置、光環給予狀態）由前後快照差異推得，因此不需要動到引擎規則、存檔或重播格式。

## 快轉與輸入鎖定

- 播放期間棋盤 `inert`，玩家無法操作；播放結束才解除。
- 動畫期間覆蓋一層透明 `.event-skip`：點擊／觸控 → 3 倍速，再點 → 12 倍速（幾乎略過）。
- 右上角「⏩ 快轉」按鈕效果相同；快轉狀態在電腦回合中持續，玩家回合開始時重置。
- 「精簡」特效模式：每段動畫上限 100ms，停頓全部略過。
- 音效全部透過既有的音效管理器。

## 多語言

新增字串（快轉、點擊快轉、進場能力、發動結界、附著、橫置、直立、各關鍵字徽章）都有英文；`LocalizeEvents` 也會翻譯事件中的卡牌文字，法術展示在英文介面顯示英文效果。

## 測試

- `SoulOath.Static/tools/effect-plan.test.mjs`：規劃器 7 項（法術展示、來源重置、關鍵字徽章、光環來源、PP 差異、回合開始不顯示橫置、批次加速）。
- `battle-feedback.test.mjs`：新增法術展示＋飛彈＋死亡順序、快轉縮短時間與按鈕存在、進場徽章順序／聖盾徽章／+500 PP。
- `WcgTests/BattleBridgeTests.cs`：WCG-021 進場事件順序、WCG-062 附著事件帶目標。
- Playwright：天梯對局逐幀擷取（中／英、桌機／手機），無主控台錯誤；截圖在 `/workspace/wcg-shots/fx2/`。

## 限制

- 重播檢視器尚未重用這套動畫（重播仍是逐步快照）。
- 只有存在於新回應中的三個演出事件會寫進新的天梯紀錄；舊紀錄不受影響。
- 光環推論只涵蓋左右相鄰與正對面的規則，其他特殊位置效果只會顯示結果、不會有光束。
