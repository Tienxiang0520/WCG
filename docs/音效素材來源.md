# 音效素材來源

網站的全部音效都放在 `WcgWeb/wwwroot/battle/audio/`，靜態版建置時也會複製一份。

- 授權：全部是 Kenney（https://kenney.nl）的 CC0 1.0 素材，可以商用，也可以放進版本庫再散布。
- 清單：每個檔案的來源網址、作者、授權、大小、長度與用途，都列在 [`WcgWeb/wwwroot/battle/audio/CREDITS.md`](../WcgWeb/wwwroot/battle/audio/CREDITS.md)。
- 原始授權文字：在同一目錄的 `licenses/`。
- 雜湊：檔案都是官方原檔，沒有重新編碼，SHA-256 記錄在 `manifest.json`，`SoulOath.Static/tools/battle-audio.test.mjs` 會逐一核對。

新增音效時：

1. 只用 CC0，或其他明確允許商用與再散布的授權。
2. 把原檔與授權文字放進上述目錄。
3. 在 `manifest.json` 補上 sha256、來源與授權。
4. 在 `../WcgWeb/wwwroot/battle/wcg-audio.js` 的 `CUES` 加上鍵名。
5. 重新產生 `CREDITS.md`。
