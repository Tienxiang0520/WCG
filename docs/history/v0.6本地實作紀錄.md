# v0.6 本地遊戲實作紀錄

2026-10-07，依cards-v0.6.md與統一設計規範更新本地遊戲；不發布Sites。

## 完成範圍

- 程式卡池由123擴充為199：117怪物、69普通法術、5反擊、8結界。關鍵字與箭頭使用獨立資料欄位，不再靠聖盾文字誤認生物自身資格。可從設計草案重新同步JSON。
- 怪物、結界與蓋牌共用固定五格。付費進場先選位置再付款；免費召喚也選空格。離場不平移，沒有換位命令。
- 直立／橫置取代舊攻擊一次與冰凍期限。轉直立恢復攻擊，142附著禁止攻擊仍有效。
- 聖盾改為交戰時詢問是否橫置1能量；資格可來自原生、133目前生命、箭頭或附著。061右、073左右、147左與敵方正對面；來源橫置不轉方向。
- 附著加成、沉默、枷鎖、限時141、短期143／165／168及181疊加分別處理，離場清除並將附著牌送回其擁有者墓地。
- 支援結界主動能力、124／153觸發橫置、127敵方法術直傷減免與185／190每回合兩次。
- 支援任意手牌0費蓋牌、宣告攻擊玩家時選翻1張、費用判定、五種反擊及198發動後附著。公開快照不揭露蓋牌原卡號、類型、PP、DP、箭頭或關鍵字。
- 有效PP用於交戰、解場門檻與700貫穿差額；160目前缺血減費與126下一隻減費，支付成本和印刷費用門檻分開。
- 組牌改最多兩個非中立派系，移除12張混色額度。舊牌組讀取保留，不自動改牌；五副v0.6預組及各階級試玩對手已準備。
- 新版AI走新版合法命令，使用固定站位、結界、反擊、保命選擇並保留能量；不用舊冰凍與多層聖盾搜尋。原階級與進度儲存保留，新版強度尚未校準。
- 正式本地對戰改為共用文字戰場，提供按鈕操作、固定格位與邊框箭頭；使用相同BattleBridge及Coordinator。原有填能量確認偏好仍有效。未製作新卡圖或動畫。

新版對局採ranked-v06規則指紋與第3版操作日誌，可重播位置、結界與蓋牌命令。舊規則未完成對局拒絕用新版重播，保留原資料；不冒充相容還原。
