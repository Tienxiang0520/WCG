# Locally bundled sound effects

Author: Kenney / Kenney Vleugels. License: Creative Commons Zero (CC0).
Original samples are unchanged; cue names, categories (UI / battle) and playback gains are set in `../wcg-audio.js`
(`../battle-audio.js` is the battle-board adapter). The turn cue is the user-selected A audition, `impactWood_heavy_000.ogg`.
Original license texts are preserved in `licenses/`. Every file, its source page, author, licence and usage is listed in `CREDITS.md`.

Official asset pages (downloaded 2026-10-07 and 2026-10-09):

- Casino Audio 1.1: https://kenney.nl/assets/casino-audio
- Interface Sounds 1.0: https://kenney.nl/assets/interface-sounds
- Impact Sounds 1.0: https://kenney.nl/assets/impact-sounds
- UI Audio: https://kenney.nl/assets/ui-audio
- RPG Audio: https://kenney.nl/assets/rpg-audio
- Music Jingles: https://kenney.nl/assets/music-jingles

`manifest.json` records the selected original filenames, pack, source, licence, SHA-256, size and duration.
No remote asset requests are made during gameplay.
