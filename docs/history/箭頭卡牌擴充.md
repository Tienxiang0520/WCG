# 箭頭卡牌擴充（站位效果）

分支：`arrow-cards`（自 `card-face-redesign` 分出；依賴 PR #5 i18n、#6 效果動畫、#7 卡面重新設計——卡面與戰場的金色三角箭頭來自 #7）

## 目標

原本只有秩序的 3 張卡（WCG-061 / 073 / 147）有箭頭，而且箭頭只代表「給聖盾」。逐張檢視全部 199 張卡，替「原本就有效果」的怪物加上站位箭頭，讓各意志都有符合個性的站位玩法：

| 意志 | 箭頭玩法 | 卡牌 |
| --- | --- | --- |
| 狂怒 | ← → 衝鋒帶隊 | 005 |
| 理智 | 依站位抽牌；↑ 橫置正對面 | 021、033 |
| 生機 | 嘲諷守線＋← → 強化兩側 | 049 |
| 秩序 | （維持）箭頭分配聖盾 | 061、073、147（未改） |
| 深淵 | ↑ 壓低正對面 PP | 085 |
| 中立 | 不新增（中立是通用牌，不強加站位） | — |

挑選原則（依使用者回饋修訂）：**原本沒有效果（「無。」）的白板卡一律不改**；只從已有效果的卡挑選，盡量「在原效果後追加」箭頭，不取代原效果（033 例外，見下表）；費用、PP、DP 全部不變。

> 修訂紀錄：第一版曾把 156／055／157／159／114 五張白板卡改成箭頭卡（並下修 PP），依回饋全部還原為原本的文字與 PP；生機改由已有「嘲諷」效果的 WCG-049 鐵木樹人承接，中立不再有箭頭卡。

## 箭頭規則

- ← →：連到己方左右相鄰格；↑：連到正對面同列格（己方第 n 格對敵方第 6−n 格）。
- 光環（005/049 加友軍、085 減敵軍）是持續效果：來源被沉默、離場或格位不再相鄰，加減值立即消失；不會作用在來源自己身上。
- 只有 061/073/147 的箭頭給聖盾（`GameEngine.ShieldArrows`），其他箭頭卡只用箭頭決定自己的效果範圍。
- 033 只橫置「直立」的正對面敵怪；正對面是空格或敵怪已橫置時改抽 1 張牌。

## 程式

- `GameEngine.V06.cs`：力量公式加入 `ArrowPower`（`ArrowAura` 表列 005／049／085）；聖盾資格限定 `ShieldArrows`；`ArrowTargets` 回傳箭頭連到的怪物。
- `GameEngine.Effects.cs`：021 / 033 進場。新分支都以「該卡有箭頭」為條件，舊版卡牌資料（無箭頭）走原本的程式路徑。033 橫置時送出「橫置」展示事件（效果動畫 PR 的徽章）。
- `GameEngine.V06Ai.cs`：電腦選格時，↑ 箭頭對著敵怪改為加分（147 的 ↑ 會給敵方聖盾，仍扣分）；左右箭頭原本就會找有隊友的格位。
- 卡面／戰場：沿用 #7 的金色三角（`face-arrow`、`.arrowmark`）；效果文字中的「【箭頭：…】」不重複印出（005／049 前綴「衝鋒；」「嘲諷；」後的箭頭標記也會移除）。

## 天梯與回顧版本

天梯存檔記錄的是卡牌資料的 SHA-256 指紋（`ranked-v06:`）。這次改了卡牌資料，所以指紋會變：

- 新增 `Data/balance-before-arrow-cards.json`（5 張卡的舊定義，嵌入資源 `WcgWeb.Balance.BeforeArrowCards`，WcgWeb 與 SoulOath.Static 都有嵌入）。
- `CardBalanceHistory.BeforeArrowCards` 還原箭頭擴充前的卡表；更早一版的 `BeforeUnlimitedFactionTriggers` 改為疊在它上面，指紋仍與當時發佈的一致。
- 測試鎖定兩個歷史指紋：箭頭前 `3664E962…A2CE`、陣營觸發無上限前 `4ED3BFBD…A194`。
- 進行中的舊對局：照舊卡續玩，顯示「本局沿用原卡牌效果與費用，下一局套用新版。」；下一局使用新版。
- 已結束的舊對局：回顧以舊卡表重新模擬，可正常播放；更早、無法辨識的版本仍顯示「這場對局使用的卡牌版本已更新，無法重新模擬回顧。」。
- `RankedAiVersion` 不需要調整：AI 與引擎的新分支只在卡牌有新箭頭時生效，舊卡表重播結果完全一致（測試以狀態快照比對）。
- **天梯星數不重置**，季別與歷季成績不受影響。

- 箭頭光環在戰場上直接反映在 PP 數字（例如 900），沒有額外的「光環來源」連線動畫。
- 中立沒有箭頭卡（可選，未新增）。
- 平衡數據是 AI 對 AI 的模擬，不代表真人勝率。
