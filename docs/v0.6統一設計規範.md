# v0.6 統一設計規範

2026-10-07，對應 `cards-v0.6.md` 的199張設計草案。本文件整理本輪確定的卡文、表示與結算方式；正式 `規則.md`、`cards.md`、`cards.ods` 與網站引擎仍是原版本，尚未同步。

## 卡文與卡面結構

每張卡統一列出卡號、卡名、類型、派系、費用、怪物PP／DP、效果形式、實體表示、卡牌效果與設計備註。目錄效果使用完整卡文，與詳文保持一致；無能力怪物明寫「無」。

| 效果形式 | 卡文方式 | 實體表示與期限 |
| --- | --- | --- |

「己方」以該效果控制者判定；不寫敵我即可指定雙方。手牌、牌庫、墓地內的卡稱「怪物牌／法術牌」，在場者稱「怪物／結界」。同義寫法統一為「施放法術」「移回手牌」「送入墓地」「生命傷害」。

## 直立、橫置與固定格位

一般怪物橫置進場，衝鋒怪物直立進場。怪物只有直立且未被禁止攻擊時才可攻擊；攻擊結束時若仍在場且直立，轉為橫置。攻擊已被宣告後，即使目標移除或攻擊被無效，也消耗此次攻擊並完成結束橫置。沒有獨立的每回合一次攻擊記錄。

效果使怪物轉直立，即恢復攻擊能力，包含剛進場與已攻擊者。禁止攻擊的卡面或附著效果仍有效；「衝鋒」不表示每次橫置都自動轉直立。141附著授予衝鋒時，施放當下使橫置目標轉直立一次，之後仍按一般攻擊規則處理。

自己回合開始重置所有己方能量、怪物與結界，卡面禁止重置者例外；對手回合開始不重置。取消冰凍狀態與期限，改用原本直立／已橫置的分支，不因第一分支橫置目標而連帶執行第二分支。

雙方各有五格橫排，同列對齊；怪物、結界與蓋牌共用五格。進場選空格，之後不能換位或平移，離場留下空格。回手或送墓後重新進場是新怪物，重新選空格並清除舊附著、加成與次數。箭頭方向依來源直立時及控制者視角判定，橫置不改方向。詳見[箭頭與站位設計](箭頭與站位設計.md)。

## 聖盾與附著

聖盾是使用能量保命的資格，來源可為原生能力、當下條件、箭頭或附著法術。每次交戰將被消滅時，目標控制者可橫置自己一張直立能量代替此次消滅。能力不因使用消耗，不增加盾層；沒有能量或不支付則正常消滅。不擋非交戰消滅、犧牲或回手。

箭頭指到空格、結界與蓋牌不提供資格；合法怪物之後進入該格立即有效。來源離場或被沉默即停止提供；其他有效來源仍各自成立。指向敵怪時由敵方支付自己的能量。

062、074、189、198附著到目標下方，直到目標離場或法術被驅散，持續提供聖盾資格；回復、抽牌、檢索與免除本次攻擊傷害只結算一次。135提供附著期間的PP加成；141保留控制者下個回合結束消滅；142提供禁止攻擊及重置。這些效果存在於附著卡，卡被驅散後停止。

沉默只無效目標卡面原生能力，不移除外部附著PP加成、短期加成或其他來源提供的聖盾。原生嘲諷、劇毒、聖盾、進場／離場、條件能力及箭頭能力均失效。沉默解除後恢復當下可用的原生能力，但不重播已錯過的進場效果。

驅散按卡文限定目標：寫「驅散附著或摧毀結界」就只有這兩種選項，不能自行擴充為摧毀蓋牌。目標上所有附著拔除後分別送入其擁有者墓地，不取消獨立的短期記憶加成或其他怪物提供的箭頭資格。

## PP、費用與短期加成

印刷PP以100為單位。交戰與卡文PP門檻都看當下有效PP：印刷值加附著、即時條件與尚未消耗的短期加減值，最低以0計。不記錄累積怪物傷害。

| 規則 | 處理 |
| --- | --- |
| 交戰 | 高有效PP消滅低者，平手雙方消滅；劇毒增加消滅結果。 |
| 聖盾 | 同次交戰的PP與劇毒合併為每隻怪物一次消滅判定。 |
| 貫穿 | 主動攻擊者存活、對象確實被該次交戰消滅，且同次有效PP差額至少700，才造成1點玩家傷害。 |
| 下一次交戰 | 包含攻擊或被攻擊怪物；攻擊玩家不消耗。完成此次交戰及貫穿判定後消耗，聖盾保命也算完成。 |
| 本回合 | 該回合結束時到期；來源離場不取消已給出的獨立加成。 |
| 181 | 固定每次效果結算當下的狂怒怪物，包含來源；後來進場不算。多次+300可疊加。 |
| 185／190 | 保留每個回合最多2次；雙方回合分別計數，來源離場重進視為新怪物。 |
| 160 | 費用依目前缺少生命減少，不累計歷史失血。 |

費用門檻、檢索、復甦與153的「2費以上／1費」依印刷費用判斷；付款才計適用減費，不能用160或126的付款減費讓原本不合門檻的牌被低費復甦。最低付款費用依減費卡的明示下限，未明示時不得低於0。

玩家已確認126、141、143、165、168的短期記憶可保留；不強制改為箭頭或額外標記，效果期限不縮短。185、190的兩次限制也保留。

## 支付、指定與觸發順序

每次行動先驗證所有費用、必要目標與空格；驗證失敗不付費。額外代價與能量在原效果前支付，代價造成的離場先處理；敗北則立即停止。卡文以冒號表示的前置支付，包含164橫置友軍、165對己方造成生命傷害與169消滅友軍，都須在抽牌或加成前完成；不把169的「消滅」換成另一種事件名稱。

抽牌、回復等後續效果依卡文順序處理。先「消滅……；若敵方無怪物」的170，在消滅與其觸發處理後判斷是否空場。195在消滅前記錄攻擊者PP，避免移除卡片後失去判斷資料。199先判斷墓地有深淵怪物，再按其卡文回收費用2以下怪物，未要求被回收的牌也必須是深淵。

怪物的必要進場指定效果沒有合法對象時，怪物仍可合法召喚，該部分不生效；本身是施放必要目標的法術無合法目標不得施放。反擊以玩家被攻擊作為觸發條件，其他無法完成的部分跳過：198沒有合法己方附著對象時仍處理免傷與回復，未附著的法術送墓地。

卡文未寫「隨機」而PP最低／最高並列時，由效果控制者選擇並列者。隨機回收從所有符合條件的卡中隨機取一張。牌庫檢視只看實際剩餘張數；沒有合格卡時不取得，其他牌依卡文置底或送墓地。檢視、移動牌庫頂卡到能量不是抽牌；空牌庫時這些動作跳過，不因此敗北。

非付費召喚使用真實手牌或墓地牌，每次選空格，按衝鋒與一般進場狀態處理，不支付僅限付費召喚的代價，也不觸發其「進場」。194的同伴條件在召喚前判斷，避免復甦怪物自行滿足條件。

## 一次攻擊的完整次序

1. 驗證直立與攻擊資格、嘲諷限制、合法目標，完成宣告。
2. 結算宣告觸發；攻擊玩家時開放一次反擊翻牌。來源或目標離場後不改打其他對象，不退回已宣告攻擊。
3. 玩家攻擊按DP傷害；怪物交戰依同組場面計算有效PP、劇毒與聖盾。雙方將死亡者一起移出戰場，再按攻擊者、被攻擊者順序結算離場；全場同批死亡先回合玩家左至右，再對手左至右。新離場觸發先處理。
4. 處理貫穿、交戰存活效果與下一次交戰加成消耗。029在此階段看對象狀態，攻擊者尚未因本次攻擊橫置。
5. 攻擊者若仍在場且直立，轉橫置；處理136的攻擊結束橫置觸發。完成後回到行動階段。

每步若任一玩家生命歸0或抽牌失敗，立即結束，不繼續其他效果。反擊197先移出蓋牌格再召喚，新嘲諷不回頭改變已宣告目標。196先橫置攻擊者不造成額外第二次橫置觸發。
