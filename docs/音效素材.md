# 本地遊戲音效

2026-10-07，使用 Kenney 官方免費 CC0 音效，取代舊介面的合成嗶聲，並接到 v0.6 對戰。

來源：[Casino Audio](https://kenney.nl/assets/casino-audio)、[Interface Sounds](https://kenney.nl/assets/interface-sounds)、[Impact Sounds](https://kenney.nl/assets/impact-sounds)。三包皆標示 CC0，可用於個人與商業專案。原始授權檔、選用檔案的雜湊與時長保留於 `WcgWeb/wwwroot/battle/audio/`；實際播放16檔，共約131 KB，單檔約0.06至0.77秒，均使用原音檔。結束回合採玩家試聽選定的A木質敲擊（impactWood_heavy_000.ogg），不混音、不改音高。

音效放在靜態版內，不依賴外部網站。預設開啟，主音量32%，各類另調音量；場上與彈窗維持原本操作。右上角喇叭按鈕切換靜音，使用獨立的 `wcg.soundEnabled` 設定，不修改玩家牌組與天梯存檔。

首次點擊會解鎖瀏覽器音訊。攻擊聲安排在前衝碰撞時、出牌聲在靠近落點時播放，結束回合按下時立即播放A木質敲擊聲，切到電腦時不重複；輪到己方時再提示一次。傷害／死亡依事件播放；玩家已在拖放動畫播放的音效不在結算時重播。相同音檔65毫秒內不重複，最多6路同時播放。背景頁不播聲，靜音或離開對局立即停止，載入失敗不阻擋對局。

5180重建後重新整理即可。原Canvas介面也沿用這套音檔，原有音效勾選控制仍可使用。未發布Sites。
