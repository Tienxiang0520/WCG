# v0.6 嘲諷盾框

2026-10-08。戰場上具有嘲諷的怪物顯示灰銀金屬盾框：上角切角，底部中央微尖。框位於滿版圖片外圍，名稱、數值和箭頭保持可見；可以攻擊時，盾框外側保留綠光。

依規則引擎提供的目前「嘲諷」狀態呈現，失去能力時會移除外框，蓋牌不顯示。出牌動畫依公開場面狀態使用同一框；攻擊和死亡動畫保留原卡片外框。素材為本地SVG，未重做卡圖，未修改規則或玩家存檔，未發布Sites。

驗證：靜態建置與27項檢查通過，包含公開狀態失去嘲諷後不再套用盾框。Chrome在5180實際召喚白銀哨衛，確認灰銀框、滿版圖片與1200／0數值正常；下一個己方回合，盾框保留灰銀外形並顯示攻擊綠光。旁邊銀色誓言衛維持普通框，右箭頭清楚可見。文字為第2層、箭頭第4層，均高於外框，未見瀏覽器錯誤或警告。截圖在忽略的 `output/v06-taunt-frame.jpg`。
