# v0.6 行動綠光

戰場上的綠光統一表示「這張卡現在可以行動」：己方怪物可攻擊，或己方主動結界符合發動條件時亮起。被動結界與蓋牌不亮；主動結界橫置或不符合發動條件時熄滅。等待電腦、動畫播放、效果選擇或彈窗開啟時不顯示行動綠光。

主動結界仍點開卡片詳情後按「發動結界」，怪物仍以拖曳攻擊。嘲諷保留盾形邊框，能行動時在盾框外發出綠光。共用戰場元件套用於人機試玩與天梯。

本地靜態試玩版使用 `node SoulOath.Static/tools/build-site.mjs .build-tmp/v06-site` 建置，於 5180 試玩，不發布 Sites、不變更玩家存檔。

驗證：靜態建置成功，27 項既有靜態檢查通過。5180 實際拖曳出牌後，思維星軌亮綠光，點開詳情發動並完成置底選擇後橫置且熄滅，下回合恢復直立後重新亮起。同場奧術回音塔不亮，敵方卡片不亮，瀏覽器無警告或錯誤。對照畫面放在忽略的 `output/v06-action-glow-comparison.jpg`。
