# 進場與填能量拖曳箭頭

2026-10-13

怪物與結界必須選擇進場格，填能量也必須放到能量區，因此這些操作恢復使用指向箭頭。拖曳時卡片留在手牌，不再用卡片副本跟隨游標；放開並通過操作判定後，才從手牌位置播放移動動畫。指定目標的法術與攻擊沿用相同箭頭。

不指定目標的法術仍保留拉出手牌、放開施放的操作。將這類卡片移到能量區時，改為箭頭；移出能量區時恢復跟隨游標的卡片。填能量優先於施放，已填過能量時顯示紅色箭頭，不能意外變成施放法術。取消拖曳會移除箭頭與卡片副本，恢復手牌顯示，不扣費。

放開當下會重新判斷呈現方式與卡片位置，避免快速切換目的地時，移動動畫使用前一畫面的起點。能量確認視窗開啟時尚未播放動畫，確認後才播放。

## 驗證

- 前端 76 項測試通過，靜態版建置與 Azure 輸出檢查通過。
- 使用獨立 agent-browser 工作階段實際操作桌面 1440×900 與手機尺寸 390×844。
- 怪物與結界在合法空格上顯示綠色箭頭，放開前沒有扣費、進場或播放卡片移動動畫；放開後從手牌飛往指定格。
- 抽牌法術在能量區與施放區間移動，可切換箭頭和卡片呈現；取消後原卡恢復顯示。
- 抽牌法術填能量只增加能量、不抽牌；已填能量時拖曳顯示紅色，放開不扣費、不抽牌、不播放移動動畫。
- 指定目標法術仍顯示箭頭；手機尺寸確認怪物進場、怪物填能量與不指定目標法術施放。頁面未水平超出螢幕，瀏覽器沒有 JavaScript 錯誤。
- 手機驗證使用瀏覽器尺寸模擬，尚未用實機驗證。

驗證輸出位於被忽略的 `.build-tmp/placement-arrows-*`；沒有改動遊戲規則、卡片數值、玩家存檔或 GitHub Actions。
