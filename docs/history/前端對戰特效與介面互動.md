# 前端對戰特效與介面互動

2026-10-09，依玩家「前端太陽春，希望對戰有爐石那種細節，其他介面互動不要那麼死板」的要求，強化 v0.6 對戰與一般頁面的手感。所有效果都是自行以 CSS、Web Animations 與程序產生的粒子製作，未使用爐石或任何外部美術、名稱與素材；未新增套件或音檔，沿用既有 Kenney CC0 音效。

只改呈現層：卡池、費用、規則引擎、AI、命令橋接、重播種子與玩家存檔都不變。特效全部畫在 `pointer-events:none` 的獨立圖層，除了原本的事件播放與移牌動畫以外，不延長任何操作鎖；送出命令與確認快照的時機與先前相同。

## 對戰

| 項目 | 效果 |
| --- | --- |
| 手牌 | 開局及抽到的牌從底部依序滑入；出牌後扇形以彈性曲線重新排列。滑鼠懸停時卡片朝游標傾斜，並有跟著游標移動的反光；可出牌／可蓋牌的卡有呼吸光暈 |
| 拖曳指向 | 指向線改為發光底層＋流動虛線，落在合法目標時出現鎖定準星；拖曳中合法落點外框脈動 |
| 出牌 | 卡片沿弧線抬起再落下；召喚落地時有衝擊環、地面揚塵，費用越高揚塵越大，2 費以上帶震屏且費用越高越強。法術飛到目標後化成光點與光環；填能量時卡片旋轉縮入能量區並濺出藍色光點 |
| 攻擊 | 先往後蓄力、快速衝刺，命中瞬間出現十字閃光、火花、衝擊環，目標被擊退，畫面依攻擊者 PP 震動，再回到原位。電腦攻擊同樣使用 |
| 死亡 | 卡片破碎成 9 塊碎片翻落淡出，並揚起塵土 |
| 傷害／回復 | 數字放大彈出後上飄，3 點以上使用大字；受傷頭像閃紅、被擊退並震屏，回復向上飄出綠色光點。頂部電腦頭像的數字改在下方顯示，不會超出畫面 |
| 場上狀態 | 可攻擊怪物外圈脈動；嘲諷框緩慢呼吸；具有聖盾資格的怪物顯示金色護盾泡；被沉默的卡圖去色；劇毒怪物的 PP 帶綠光。依現行卡面簡化，不增加文字 |
| 能量 | 能量水晶以漸層呈現，新增時彈出、支付時縮小變暗，可用數字變動時跳動 |
| 回合 | 換手時畫面中央出現「你的回合」或「電腦回合」橫幅；頂部回合標籤、當前行動方頭像亮框，戰場邊緣依行動方帶綠／橘色氛圍 |
| 結束回合 | 沒有可出、可填能量、可攻擊或可發動的行動時，按鈕持續發光提示（只是提示，不會自動結束） |
| 生命 | 生命數字變動時跳動；2 點以下持續紅色脈動 |
| 對局結束 | 依結果顯示「勝利」或「敗北」橫幅，天梯結算視窗彈入 |
| 環境 | 戰場背景緩慢飄動的微光粒子 |
| 按鈕與彈窗 | 懸停浮起、按下壓縮；效果選擇、詳情與填能量確認彈入，指定目標提示由上滑入 |

右上角新增「✨ 特效」切換鈕，可改為「◌ 精簡」。精簡模式關閉粒子、震屏、碎裂、環境動態與循環光暈，移牌與事件動畫縮短為原本的減少動態版本；設定存在本機 `wcg.motion`，未設定時依作業系統的「減少動態效果」。這個設定同時套用到全站頁面動畫，不影響玩家牌組、天梯存檔或填能量確認設定。

## 其他頁面

- 換頁時內容淡入上移；側邊欄滑過圖示放大，目前頁面左側有亮條。
- 所有 Bootstrap 按鈕滑過浮起、按下壓縮；輸入框焦點過渡。
- 牌組構築室與卡牌圖鑑：卡片滑過浮起、微傾並掃過一道反光；篩選後新出現的卡片依序浮入；卡圖載入時短暫顯示骨架閃光（最多約 4 秒，之後停止以免持續耗電）。
- 牌組清單新增的卡牌滑入，張數改變時數字跳動；張數進度條平滑變化；驗證錯誤訊息輕微左右晃動。
- 儲存牌組成功時右下角跳出提示，約 3 秒後自動淡出；原本面板內的成功訊息保留。
- 卡片詳情與牌組選擇視窗彈入；天梯大廳星數浮入、開始按鈕有反光掃過，結算視窗彈入。

## 實作

- 新增 `WcgWeb/wwwroot/battle/battle-fx.js`：震屏、粒子、衝擊環、閃光、擊退、碎裂、橫幅與特效設定。粒子同時最多 90 個，結束後自動移除圖層；卸載或切換為精簡時立即取消全部效果。
- `battle-feedback.js` 在原有公開事件播放中加入上述效果；只讀公開事件與公開場面，電腦背面能量與蓋牌仍不顯示卡名。
- `fan-drag.js` 加入手牌傾斜、指向線與準星、弧線出牌與攻擊蓄力；接觸特效只在動畫中途觸發，結果仍以引擎結算為準。
- `BattleBoard.razor` 只新增呈現用 class（狀態、回合、低生命、無行動提示）與特效切換鈕；`MainLayout.razor` 在載入時同步特效設定。
- 樣式放在 `BattleBoard.razor.css`、`battle/battle.css`、`wcg.css` 與 `NavMenu.razor.css`。頁面進場動畫使用 `backwards` 填充，結束後不留下 transform，避免影響固定定位的彈窗。

## 界限

- 手機直向版面維持原本的最小寬度 600px 與水平捲動，這次只讓頂部按鈕不換行，沒有重新設計手機版面。
- 原 Phaser 版（`board.js`）目前沒有頁面使用，未修改；`/legacy` 原版介面只受全站按鈕與卡片樣式影響。
- 沒有新增音效或音檔，橫幅與碎裂沿用既有的回合、死亡等音效。
