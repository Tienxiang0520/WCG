# 魂誓 v2.0 設計憲法草案（實體優先重構）

> [!NOTE] 草案狀態
> 本文件為 **v2.0 大改第一步** 的設計基準，現行正式規則與網站引擎仍以 [規則.md](../規則.md) 及 [cards.md](../cards.md) 為準，尚未套用至程式碼或卡表。

## 設計目標

保留《魂誓》最核心的實體樂趣（7 點血快節奏、手牌背面填能量、PP/DP 無累積傷害、固定 5 格站位與邊框箭頭），同時徹底消除桌上遊玩的閱讀與操作負擔：

1. **全卡池中文上限 35 字（權重 ≤ 70）**：不靠縮小字級硬塞 63×88 mm 卡面。
2. **每張卡只做 1～2 件事**：拿掉「條件沒中改抽 1 張」的保底補丁與多段疊加能力。
3. **零外來配件、零牌庫底操作、零口頭記帳**：不拿骰子、不用代幣、不從牌庫底抽牌墊牌。
4. **規則書「零點名例外」**：規則書不出現特定卡號或卡名；卡面不重複寫規則書已知的通則。

## 一、基本規格與流程

- **牌組**：恰好 50 張，同名卡最多 4 張，最多 2 個派系（中立不計）。
- **生命**：上限 7 點（先攻 6 點起、後攻 7 點起）。後攻額外獲得 1 張 `幸運幣`（0 費，用完進墓，不計入 50 張）。
- **起手與抽牌**：雙方起手 7 張；先攻首回合不抽牌。需要抽牌時牌庫已空立即敗北（檢視、填能等非抽牌動作不敗北）。
- **回合流程**：
  1. **重置與抽牌**：重置己方所有能量、怪物與結界，抽 1 張牌。
  2. **行動階段**（順序自由）：
     - 每回合可將 1 張手牌**背面朝上、橫置**放入能量區。
     - 橫置直立能量支付費用，召喚怪物（橫置進場，除非有`衝鋒`）、施放法術或放置結界（共用己方 5 格，進場選空格且不可換位）。
     - 指揮直立且未受限制的怪物攻擊（攻擊敵方怪物或敵方玩家；敵方有`嘲諷`時須先攻擊嘲諷），攻擊後橫置。
  3. **回合結束**：所有「本回合」效果到期。

## 二、數值縮放與門檻簡化

### 1. PP 除以 100（100 → 1）

全面去掉 PP 尾數的兩個零，將四位數壓成 1～35 的整數，方便桌面瞬間心算並釋放卡面空間。

| 項目 | 現行 (v0.6) | v2.0 尺度 |
| --- | --- | --- |
| 1 費白板基準 | 1000 PP / 1 DP | **10 PP / 1 DP** |
| 2 費白板基準 | 1300 PP / 1 DP | **13 PP / 1 DP** |
| 3 費白板基準 | 1600 PP / 1 DP | **16 PP / 1 DP** |
| 4 費白板基準 | 1900 PP / 1 DP | **19 PP / 1 DP** |
| 5 費白板基準 | 2300 PP / 2 DP | **23 PP / 2 DP** |
| 6 費白板基準 | 2600 PP / 2 DP | **26 PP / 2 DP** |
| 7～9 費上限 | 2900～3500 PP | **29～35 PP** |
| 常見增減幅 | ±200 / ±300 / ±500 | **±2 / ±3 / ±5** |

### 2. 廢除「印刷 PP vs 當下 PP」雙軌制

- **場上全部一律看當下 PP**（印刷 PP ＋ 附著 ＋ 箭頭／靈氣 ＋ 本回合加減，最低為 0）。
- **解場與檢索門檻統一只留兩類**：
  - **費用門檻**（最推薦，印在右上角永遠不變）：`費用 2 以下`、`費用 3 以下`、`費用 4 以上`。
  - **戰力門檻**（僅留 2 條基準線，一律看當下 PP）：**`PP 10 以下`**（小怪）與 **`PP 18 以上`**（大怪）。取消 `1200`、`1600`、`2300`、`1300~1700` 等零碎門檻。

### 3. 配合 7 點血量的 DP 設計規範

在 **7 點生命（先攻 6 點）** 的前提下，1 點 DP 相當於其他遊戲 3～4 點攻擊力。現行卡表 254 隻怪物中 **72% 為 1 DP、0 DP 僅 18 隻（7%）**，3 費卻有 11 隻 1 DP `衝鋒`，導致前期搶血過快、沒有空間展開 5 格陣型。v2.0 採用**「角色分流＋階梯式 DP」**：

#### (1) DP 與怪物定位掛鉤（提高 0 DP 比例至 25%～30%）
- **0 DP（功能／盾牆／交換型）**：不該一邊賺牌或擋人、一邊每回合踢玩家血。以下兩類預設為 **0 DP**：
  1. **1～2 費強功能怪**：進場抽牌、檢索、回血、法術觸發或純箭頭輔助（例：`潮間採集者`、`嫩根幼苗`、`汲泉修女`）。
  2. **1～3 費防禦盾牆**：高 PP 的純`嘲諷`或`格擋`怪物（以多出來的 PP 或低費換取 0 DP）。
- **1 DP（標準戰鬥主力，1～4 費主體）**：一般交換與進攻單位；1 費給 1 DP 時須為純快攻打手或無進場賺牌能力（PP 約 7～8，白板 10）。
- **2 DP（後期壓制與終結者，5 費以上為主）**：
  - **4 費以下原則不給 2 DP**（除非是無異能純白板，或帶有棄牌／自傷等顯著負面代價）。
  - **5～6 費**開始作為常規 2 DP 戰力線。
- **3 DP（純巨獸天花板，7 費以上限定）**：僅給予高費大型生物，且 **不與 `衝鋒` 同時出現**。

#### (2) 前期搶血與爆發防呆
- **衝鋒門檻**：`衝鋒` 怪物不給高 PP，3 費衝鋒維持 `1 DP` 且 PP 低於同費白板（約 `11～12 PP`）；4 費以上才允許高戰力衝鋒；**禁止「3 DP ＋ 衝鋒」**（避免先攻滿血被一腳踢掉一半）。
- **禁止無限打臉與 DP 翻倍**：
  - 取消「DP 翻倍」法術（原 `345`）。
  - 任何「轉為直立」效果（原 `391`、`394`、`396`、`399`）只能**多攻擊怪物一次**，或在規則層限定 **「每隻怪物每回合對玩家最多造成一次戰鬥傷害」**，杜絕 7 血被單卡連擊秒殺。
- **DP 加成只靠公開單卡、上限 +1**：取消 `DP 牌` 墊底疊加後，法術或條件給予的 DP 加成（如 `重蹄蹄鐵`、低血強化）單張最多 `+1 DP`。

## 三、實體狀態規範（只有「正面附著卡」）

徹底取消 **牌庫底墊牌**（倒數牌、DP 牌、血誓、聖泉）與 **將手牌或來源卡塞在怪底下當聖盾**，避免一隻怪底下同時混雜正面/背面/直放/橫放四種卡片。

- **桌面只允許一種底部疊放物：正面朝上的附著卡**（塞在怪物下方露出一條卡名與效果文字）：
  - **增益／減益／關鍵字附著**（含授予`格擋`的法術）：正面塞怪物下方；離場或被`驅散`時進擁有者墓地。
  - **一次交戰附著**（原 143、165、168 類）：統一寫成「`附著：下一次交戰 PP +5，戰後送墓。`」不再靠規則書點名卡號。
  - **沉默**：沉默法術正面壓在目標文字區上，代表其卡面原生能力失效；離場或被`驅散`時進墓地。
- **控制權簡化**：只保留「轉 180 度奪取直到回合結束」，取消「跨邊移格＋壓底」的永久控制。
- **公開資訊原則**：所有條件只看「當下桌面看得到的狀態」（生命值、手牌張數、墓地張數、場上怪物／格位與箭頭指向），不設計需記帳的「本回合回血總量」或「這張卡本回合是不是從能量區來的」。

## 四、反擊：單一窗口（零回合內打斷）

- 取消「敵方施放法術時」與「敵方付費召喚時」的反擊時機，避免實體對戰每出 1 張牌都要詢問對手是否反應，也省去退費／無效算不算施放等規則爭議。
- **唯一反擊時機**：**`【反擊】受到傷害時：`**
  - 扣血後，可從手牌支付能量打出至多 1 張合法反擊牌；反擊造成的傷害不再引發反擊。
  - （註：若後續採納「蓋牌反擊」草案，亦維持僅在玩家受到攻擊時翻開，同樣不打斷對方行動階段出牌。）

## 五、標準關鍵字與卡面文法

### 1. 八大關鍵字（卡面直接列出，不附括號說明）

| 關鍵字 | 規則定義 | 取代的舊寫法 |
| --- | --- | --- |
| **嘲諷** | 敵方怪物必須優先攻擊具有嘲諷的怪物（橫置時仍有效）。 | — |
| **衝鋒** | 直立進場，當回合即可攻擊。 | — |
| **格擋** *(新)* | 直立的此怪物被攻擊且將被消滅時，改為橫置並存活（法術消滅不擋）。 | 聖盾（塞手牌／炸箭頭來源） |
| **貫穿** | 主動攻擊在交戰中消滅敵怪且自身存活時，對敵方玩家造成 1 點傷害。 | — |
| **劇毒** | 交戰時不論 PP 高低皆消滅對方（直立`格擋`可擋）。 | — |
| **越陣** *(新)* | 攻擊時可以無視敵方嘲諷。 | 「嘲諷擋不住此怪物」「攻擊時可以無視嘲諷」 |
| **魔免** *(新)* | 不能成為法術的目標（不指定目標的全場法術仍可影響）。 | 「不能成為法術的目標」 |
| **沉默** | 使目標卡面原生能力失效；不影響外部附著卡與他怪箭頭。 | — |

### 2. 六個標準前綴

| 前綴 | 意義與預設規則 |
| --- | --- |
| `進場：` | **僅限從手牌付費召喚時觸發**。凡「免費召喚」一律不觸發進場，卡面不再寫「（不觸發進場）」。 |
| `陣亡：` | 被消滅或犧牲送入墓地時觸發；回手不算。 |
| `回合開始：` | 你的回合開始重置並抽牌後觸發。 |
| `回合結束：` | 你的回合結束時觸發。 |
| `橫置：` | 須處於直立狀態方可使用，支付橫置此卡後結算。取代「主動：橫置此卡：」。 |
| `附著：` | 法術牌置於目標怪物下方，附著期間持續有效；目標離場時送入擁有者墓地。 |

### 3. 固定動詞與語法（不可混用同義詞）

- **不寫敵我＝皆可選（通則）**：單體效果只寫 `1 隻怪物`、`1 位玩家` 而未標明己方／敵方時，代表敵我皆可選；僅「犧牲／回手自己低費卡／全體不對稱解場／自動擇低高」等需要限制邊界時才標註 `己怪` 或 `敵怪`。
- **箭頭表示**：卡面文字**不寫 `【箭頭：...】`**（由卡框三角形呈現），直接以方向符號開頭作為段落，且置於卡面最後一段：
  - 例：`←→ 友軍 PP +2。`、`→ 友軍獲得格擋。`、`↑ 敵怪 PP -3。`
- **免費召喚**：`免費召喚 1 隻費用 2 以下的怪物。`（預設進己方空格、橫置進場、不觸發進場；若需直立進場才加註「直立進場」）。
- **檢視牌庫**：`看牌庫頂 3 張，選 1 張［條件］入手，其餘置底。`
- **回復生命**：`回復 1 生命。`（預設回復自己；若雙方皆可指定則寫 `1 位玩家回復 2 生命`）。
- **玩家傷害**：`敵方玩家 1 傷害。` 或 `對敵方造成 1 傷害。`（預設對敵方玩家造成傷害；自傷寫「失去 1 生命」或「受 1 傷害」）。
- **回手**：`將 1 隻怪物移回手牌。`（預設回到該卡擁有者的手牌）。
- **驅散**：`驅散 1 隻怪物或 1 個結界。`（移除該怪物所有附著卡含沉默送墓，或摧毀該結界）。
- **決鬥**：`令 A 與 B 決鬥。`（兩隻怪物立刻交戰，無視嘲諷；雙方皆算被攻擊）。

## 六、五大派系機制收斂（卡池瘦身方向）

下一步（Step 2）縮編卡池時，建議從 426 張精簡至 **220～240 張**（各派系約 38～42 張＋中立約 30 張），每系收斂為「**1 個經典玩法 ＋ 1 個代表實體機制**」：

| 派系 | 核心定位 | 保留與聚焦的代表機制 | 退場／整合的高摩擦機制 |
| --- | --- | --- | --- |
| **狂怒** | 快攻、直傷 | `衝鋒`、`越陣`、犧牲換傷、低血（生命 ≤ 3）爆發 | 能量區燒牌進墓、繁複連擊次數上限 |
| **理智** | 過牌、控場 | 看牌庫頂置底、橫置鎖定、己怪／敵怪回手節奏 | 施法/召喚打斷反擊、倒數墊牌 |
| **生機** | 跳費、陣型 | 填能量加速、高身材`貫穿`、`← →` 箭頭鄰接強化 | 牌庫底橫放 DP 牌、多層根脈計數 |
| **秩序** | 護衛、回復 | `嘲諷`、`格擋`（自帶／箭頭／附著）、補血收益、`決鬥` | 聖盾（手牌塞底／炸箭頭來源）、聖泉墊牌、血誓墊牌 |
| **深淵** | 換怪、墓地 | `劇毒`、堆墓與墓地條件復甦、腐蝕箭頭／附著減 PP | 翻牌庫頂類型輪盤、跨卡記憶永久控制 |

## 七、卡面字數驗收標準

進入 Step 2 重整卡表時，每張卡須通過以下檢核：
1. **卡文權重 ≤ 70**（約 35 個全形字內，保證在 63×88 mm 實體卡上都能以預設字級或第一段微縮清晰印出）。
2. **無括號補充規則**（僅允許明確的數值上限如 `（最多 3 張）` 或代價性質如 `（生命代價）`）。
3. **無跨回合／跨區域的隱藏狀態追蹤**（雙方光看桌面即可驗證所有條件）。
