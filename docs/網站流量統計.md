# 網站流量統計（Application Insights）

正式網站 <https://wcggametienxiang0520.z11.web.core.windows.net/> 用 Azure Application Insights 計算訪客人數。

## 收集什麼

- **頁面瀏覽**：開啟網站與站內切換頁面（例如從首頁進到構築室）各記一筆。
- **匿名訪客代號**：SDK 產生的隨機代號，用來分辨「幾個人」，不含帳號、名字或電子郵件。
- **大概位置與瀏覽器**：Azure 依 IP 推算國家／城市（IP 本身不保存）、瀏覽器與作業系統。

不收集：自訂事件、卡牌、牌組、存檔、對戰內容、API 請求。只有正式網站的網域會送資料，本機開發（localhost）與非 Azure 建置都不會載入。廣告攔截器擋掉腳本時遊戲照常運作，只是不會被計到。

## 費用上限

- 資源：資源群組 `wcg-game-rg`、區域日本東部（japaneast）。
  - Log Analytics 工作區 `wcg-logs`：PerGB2018，每日上限 0.1 GB，保留 30 天。
  - Application Insights `wcg-web-insights`：每日上限 0.1 GB。
- 每月前 5 GB 免費，0.1 GB／天最多約 3 GB／月，所以費用預計為 0。超過每日上限當天就停止收資料，隔天自動恢復。

連線字串寫在 `SoulOath.Static/wwwroot/analytics.js`（`WcgWeb/wwwroot/analytics.js` 是同一份）。它本來就會出現在網頁裡，是公開資訊，不是密碼。

## 怎麼看訪客

入口網站：Azure 入口網站 → 資源群組 `wcg-game-rg` → `wcg-web-insights` → 左側「監視 → 記錄」（Logs），貼上下面的查詢執行。也可以看「使用量 → 使用者」。資料進來通常要 2–5 分鐘。

最近 30 分鐘有幾個人：

```kusto
pageViews
| where timestamp > ago(30m)
| summarize 訪客 = dcount(user_Id), 頁面瀏覽 = count()
```

今天（台北時間）的人數：

```kusto
let 台北今天 = startofday(now() + 8h) - 8h;
pageViews
| where timestamp >= 台北今天
| summarize 訪客 = dcount(user_Id), 頁面瀏覽 = count()
```

最近 7 天每天的人數（台北時間）：

```kusto
pageViews
| where timestamp > ago(7d)
| summarize 訪客 = dcount(user_Id), 頁面瀏覽 = count() by 日期 = bin(timestamp + 8h, 1d)
| order by 日期 desc
```

最近的瀏覽紀錄（台北時間）：

```kusto
pageViews
| where timestamp > ago(1d)
| project 台北時間 = timestamp + 8h, 頁面 = name, 網址 = url, 訪客 = user_Id, 國家 = client_CountryOrRegion, 瀏覽器 = client_Browser
| order by 台北時間 desc
| take 50
```

## 怎麼關掉

- 暫停收集：把 `SoulOath.Static/tools/build-site.mjs` 裡加入 `addAnalytics` 的那段拿掉再部署，網站就不會載入腳本。
- 完全移除：再到資源群組刪除 `wcg-web-insights` 和 `wcg-logs`。

## 隱私說明

SDK 會在瀏覽器存一個匿名代號（cookie `ai_user`，以及工作階段的 `ai_session`），用來計算不重複訪客。代號是隨機的，不連結到遊戲帳號或存檔；清除瀏覽器資料就會換新代號。
