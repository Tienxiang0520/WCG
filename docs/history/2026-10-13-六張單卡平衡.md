## 前後配對模擬

使用同一份 30 副完整強牌表、種子基數 `10300000`、每組 32 個種子，全部 435 組對局交換先後手。AI 5、AI 3 各測新版及舊版 27,840 場，合計 **111,360 場**。每流派每版本每策略有 1,856 場。

| 流派 | AI 5 舊版 → 新版 | AI 3 舊版 → 新版 |
| --- | --- | --- |
| 生機・荊棘毒牙 | 60.08% → 56.03% | 54.09% → 47.58% |
| 生機・巨獸奔襲 | 55.06% → 52.64% | 59.75% → 55.55% |
| 秩序・誓約審判 | 62.07% → 60.72% | 57.17% → 56.68% |
| 深淵・噬魂獻祭 | 42.56% → 46.66% | 44.40% → 48.11% |
| 深淵・亡者交換 | 51.94% → 56.84% | 49.62% → 53.56% |
| 生機・根鬚覺醒 | 46.77% → 49.14% | 43.86% → 47.14% |
| 狂怒・焦土控場 | 37.18% → 36.42% | 49.84% → 48.76% |
| 狂怒・戰鼓狂潮 | 43.86% → 43.75% | 45.53% → 47.63% |

荊棘、巨獸下降，獻祭、亡者與根鬚提升。誓約審判仍是 AI 5 下最高的一副。滅絕怒火雖然降費，焦土控場在兩種策略的整體勝率都沒有提升：其他牌組也被補強，改一張解牌不足以解決整副牌的問題，後續仍要比較它的展開與終結能力。

AI 5 全流派範圍：37.18%–62.07% → 36.42%–60.72%；AI 3：39.28%–60.83% → 38.74%–61.31%。先手勝率分別為 69.30% → 69.52%、62.93% → 62.98%，先手優勢仍未解決。

這是六張一起改的結果，不能把每副牌的變化全部歸因於其中一張；也是 AI 模擬，不代表真人勝率。單卡試改的先前樣本用來挑選方向，本次用不同種子、較大樣本驗證整套更新。完整 30 流派摘要見 [比較數據](2026-10-13-六張單卡平衡數據.json)。

## 舊局與雲端存檔

`balance-before-strong-build-adjustment.json` 保存這六張完整的舊定義，包含參與卡池指紋的設計備註。歷史卡池先還原本次更新，再依序還原更早版本，避免把兩次改版拼成不存在的混合卡池。

更新前開始的天梯對局仍使用舊值，續玩、星數與回顧保持一致；下一場才使用新值。雲端驗證器同時支援本次新版、強牌表版與上一輪數值平衡前的對局。測試使用隔離存檔，不覆蓋真實玩家資料。

## 重現與驗證

完整舊卡池可從基準 Git 版本取得，而六張歷史差異檔不能直接當作完整卡池：

```bash
mkdir -p output/balance/six-card-check
git show 679bdf4:WcgWeb/Data/cards.json > output/balance/six-card-check/before-cards.json
git show 679bdf4:WcgWeb/Data/ranked_decks.json > output/balance/six-card-check/decks.json
dotnet run --project tools/BalanceLeague -c Release -- \
  --cards output/balance/six-card-check/before-cards.json \
  --decks output/balance/six-card-check/decks.json \
  --out output/balance/six-card-check/before-ai5.json \
  --seeds 32 --seed-base 10300000 --ai 5 --threads 4
```

新版將 `--cards` 改成 `WcgWeb/Data/cards.json`，並使用不同輸出檔。AI 3 將 `--ai 5` 改成 `--ai 3`。未來再次改卡後，要從本次發布版本取出卡池以重現本輪新版。

遊戲測試 391 項、雲端 API 17 項、前端建置測試 91 項全部通過。卡表及分段牌表產生器檢查通過；RankedCheck 完成牌表合法性、低段微調及分段抽選檢查。舊卡池完整還原與六張以外資料保持一致的比較通過。

原始模擬與建置紀錄放在忽略目錄 `output/balance/2026-10-13-six-cards/`。
