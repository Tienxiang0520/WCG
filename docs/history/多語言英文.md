# 多語言：英文介面（i18n-english）

## 目標
在「設定」加入介面語言切換，新增 English；繁體中文仍是預設。伺服器版（WcgWeb）與靜態版（SoulOath.Static）共用同一套在地化層。存檔、天梯紀錄與回顧不受語言影響。

## 架構
- **Localizer**（`WcgWeb/Services/Localization/Localizer.cs`）：以繁體中文原文當作 key（gettext 風格），英文模式才查表；中文模式直接回傳原文，零成本。
  - `L["中文"]`、`L.F("第 {0} 回合", n)`、`L.Text(引擎訊息)`、`L.CardName/CardText(id, …)`、`L.DeckName(deck)`、`L.Will(...)`。
  - 查表順序：完全相符 → 卡名（依中文） → 牌組名稱／描述／流派短名 → 樣板（含 `{0}` 的 key 轉成正規表示式，長者優先；參數遞迴翻譯，無法翻譯的參數如玩家自訂名稱原樣保留） → 去掉【】 → 依分隔符（換行、` · `、`；`、`。`、`，`、`、`、`：`、` / `）拆段翻譯。
- **資源檔**（`WcgWeb/i18n/`，以 EmbeddedResource 嵌入兩個版本，`WithCulture="false"` 避免被當成衛星組件）：
  - `en.json`：介面、引擎訊息、教學 13 課與導覽、規則頁，約 1,260 筆。
  - `cards.en.json`：199 張卡的英文卡名與效果文字（依卡號）。
  - `decks.en.json`：預設與天梯 80 套牌組名稱與描述（依牌組 id）。
- **存檔與回顧**：引擎、存檔、天梯紀錄、回顧事件仍保存原本的 id 與中文標準字串；只在畫面渲染時翻譯，所以切換語言不會改動任何存檔，也不需要版本升級或重置。對戰動畫事件（`presentEvents`）送到 JS 前才複製一份英文標籤，引擎本身不變。
- **語言選擇**：存在玩家設定（`player_profile` 新增可選欄位 `Language`，舊存檔沒有此欄位照常讀取；換頭像會保留語言）。
  - 沒有存過選擇時才看瀏覽器語言：第一偏好是 `en` 或 `en-*` 才用英文，其餘（含不確定）一律繁體中文。
  - 伺服器版的 Localizer 是每個連線一份（偵測依各自的瀏覽器），存過的選擇寫在共用設定檔。
  - `i18n.js` 設定 `<html lang>`，並把目前語言寫入 `localStorage["wcg.language"]`，讓靜態版下次的載入畫面（`startup.js`）一開始就用正確語言。
- **即時切換**：MainLayout 的 `.page` 以 `@key="L.Language"` 重建頁面子樹，不需重新整理；教學提示放在子樹外，切換時不會重跳。
- **JS 端**：對戰橫幅（你的回合／電腦回合／勝利／敗北）、拖曳格位提示、載入畫面、存檔匯出檔名依 `<html lang>` 切換；JS 拋出的錯誤訊息維持中文，由 C# 顯示時經 `L.Text` 翻譯（node 測試的中文預期不變）。
- **英文排版**：以 `:root:lang(en)` 選擇器調整：卡名可換兩行、手牌／場上卡名縮字、回合標籤、教學標題、回顧卡名換行。桌面 1440×900 與手機 390×664 都檢查過沒有溢出。

## 測試
- `WcgTests/LocalizationTests.cs`（14 項）：
  - 字典每個值都是非空英文、無漢字、`{n}` 佔位符一致（「再」「步」兩個數字前後的填充字刻意為空）。
  - 199 張卡與全部牌組都有英文名稱與效果。
  - 掃描兩個版本所有 Razor 元件裡傳給 `L[...]`／`L.F`／`L.Text` 的字串（含三元運算子兩側），英文翻譯不得含漢字。
  - 教學 13 課所有標題、摘要、步驟、提示與導覽。
  - 天梯牌位標籤與電腦策略。
  - 所有預設牌組兩兩 AI 對戰，收集畫面快照中的每則紀錄、選擇標題與選項、狀態，以及引擎動畫標籤，全部要能翻成英文。
  - 瀏覽器語言偵測規則；舊設定檔相容、換頭像保留語言、已存選擇優先於瀏覽器。
- `SoulOath.Static/tools/startup.test.mjs` 新增：載入畫面依已存語言／瀏覽器語言切換，預設中文。
- `tools/i18n-scan/`（Playwright，`npm i` 後 `node flow.mjs <網址> desktop|mobile <標籤>`、`node ranked.mjs ...`）：
  - 在設定切到 English，走過大廳、教學、天梯、牌組構築、卡牌圖鑑、規則、卡片預覽、選牌組、對戰（數回合、選擇、紀錄）、教學課程與導覽、天梯對戰→投降→結算→回顧（多步）→紀錄。
  - 掃描文字與 title／aria-label／placeholder／alt 的漢字（只允許「繁體中文」這個語言名稱），有漢字或主控台錯誤就失敗，並列出溢出的按鈕與標籤。

## 已知限制
- 伺服器版是單人本機設定檔，語言選擇由所有分頁共用（未選擇時才依各分頁瀏覽器偵測）。
- 對戰紀錄與引擎訊息仍以中文標準字串保存，在顯示時以樣板翻譯，而非完全結構化的資料；新增引擎訊息時須同步加入 `en.json`（`LocalizationTests` 會抓出遺漏）。
- `/legacy` 舊版對戰頁（Home.razor）與開發用 BattleLab 未完整翻譯。
- 切換語言會重建頁面子樹，牌組構築中尚未儲存的編輯會遺失。
- 手機版扇形手牌本來就互相重疊，卡名只在最上層卡片完整顯示（中英文相同）。
- 頁面 `<title>` 以外的 SEO meta（靜態版 index.html 的 description）維持中文。
